# v0.12.2：声音感知开关与 USB 提前授权

## 浅层开关

设置首页的“声音感知”现在使用与“双眼观看”等选项相同的蓝色胶囊开关：

- 点击右侧开关开启 / 关闭声音类型识别及方向显示。
- 点击左侧名称进入连接、校准和光晕外观设置，不会顺便改变开关状态。
- 遥控器选中该行后，A 切换；右为开启、左为关闭。重复按右不会不断重新开启。
- 戴眼镜时也可从“深层设置 → 声音感知设置”进入参数页。

主设置的横屏左侧文字布局、蓝色控件，以及 X 字幕语言小窗的上下布局继续保留。前方 / 左右校准、Tina 同传修复、本机 Key 自动回填均保留。

## USB 为什么不必每次都问

现在进入应用时就检查已保存的小板或已识别的 CH340。若已经有系统授权，直接准备连接；尚无授权时，提前弹出系统请求，不再等到开启声音识别才开始准备。

应用保持前台时，关闭声音感知只暂停识别与方向显示，**保留串口连接就绪**。再次开启时复用连接，不反复关闭 / 重开串口。自动准备 USB 不会自动打开手机麦克风。

进入后台仍释放串口，返回后重新检查系统权限。用户明确点“断开并关闭读取”、改变波特率 / 数据格式、拔掉设备或系统断开时，也会释放或重建连接。

## 系统限制与默认打开

首次连接、重新插拔或系统收回授权时，Android 仍可能要求确认；应用不能自行授予 USB 权限。Android 官方说明临时 USB 权限通常持续到设备断开：[USB 主机与授权](https://developer.android.com/develop/connectivity/usb/host)。

本版为当前 `1A86:7523` 小板注册了 USB 连接处理入口。如果插板时系统询问“默认使用听见视界打开此 USB 设备”一类选项，可按你的意愿设为默认。是否提供该选项、下次是否直接授予权限，由手机系统决定；本次没有替你修改系统默认应用或安全设置。

拒绝一次授权后，不会在同一次设备连接中反复自动弹窗。如果需要重新允许，在“声音感知”参数页点 **重试 USB 授权**；也可在详细小板设置手动选择设备连接。

多个同型号小板时不会猜测要用哪一个，仍需你选择。授权查询以 Android 的 `hasPermission` 为准，应用没有把“曾经弹过窗”当成已授权。

## 建议验证

1. 手机接回小板，打开应用，完成首次系统 USB 确认。
2. 不拔线，反复开关浅层“声音感知”。正常情况下复用同一连接，不应因开关而反复请求 USB 授权。
3. 关闭时不显示旧方位，再开启、发声后有新的光晕 / 识别。
4. 拔插或后台返回后，按实际系统提示处理；需要时点“重试 USB 授权”。

若系统仍反复弹窗，应结合是否发生供电波动 / 设备重连及应用诊断判断。新增 `permissionRequests / portOpens / portCloses / standby` 状态字段便于区分“应用发起请求”与“串口连接重建”，不会记录密钥或音频。
