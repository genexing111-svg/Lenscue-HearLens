## 麦克风真实识别

用户在系统提示中授权，手动开始并停止；没有用合成音频替代真实麦克风验收。

ASR 已通过：内置麦克风，16000 Hz 单声道 PCM16LE；964 包 / 616960 字节，即 19.28 秒音频，收到 73 条消息。返回实际原文包括“你好你好。”“hello hello.”，以及多段中文。收到 `sentence_id`、`begin_time`、`end_time`、`sentence_end`、`words`、`stash` 等真实字段。最终收到 `task-finished`，状态 FINISHED，麦克风 false。云端偶尔以空句结束，原有非空句仍保留在页面列表。

Live 已通过：1513 包 / 968320 字节，即 30.26 秒真实音频，收到 164 条消息。原文“it's working”对应英文“It's working.”，原文“没事可以”对应英文“It's fine. That's okay.”。实际收到 `id`、`speakerId`（含 1 和 2）、`startMs`、`endMs`、`original`、`originalFinal`、`translations.en`、`translationFinal.en`。原文和译文完成标志均为 true，最终 `session.finished`，状态 FINISHED，麦克风 false。用户确认“完全正常”。这证明说话人字段可接收，不代表已经验收多人分离准确率。

初次 ASR 无录音检查曾发现诊断脱敏规则将 `task-finished` 的一部分误判为密钥；已修正并增加回归断言。最终 APK 的上述真实 ASR 测试已正确显示 `task-finished`。
