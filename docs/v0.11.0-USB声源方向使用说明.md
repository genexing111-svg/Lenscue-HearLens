# v0.11.0：USB 声源方向小板与正前方校准

本版在现有 v0.10.4 的相机、双眼、无线、语音字幕和遥控功能上增加 USB 串口方向接口。小板通过 USB OTG 直接连接手机，手机解析小板给出的角度；电脑不需要参与读取。不会给小板刷固件，也不向串口发送启动、校准或其他业务命令。正前方偏移保存在手机里。

## 已识别的小板输出

2026-10-06 在电脑识别到 `USB-SERIAL CH340 (COM3)`，VID `1A86`、PID `7523`。启动日志为 ESP32-C3。波特率为 **115200**，串口参数 **8 数据位、无校验、1 停止位（8N1）**。启动后真实收到：

```text
angle: 354.0 deg
angle: 355.0 deg
angle: 1.0 deg
angle: 339.0 deg
```

默认“自动”格式已能识别这些记录。CH340 是 USB 串口桥接芯片，ESP32-C3 是启动日志中的处理器信息；仍不能由此确定麦克风阵列的厂家型号、定位精度或麦克风数量。

## 手机直连测试步骤

1. 安装 `听见视界-v0.11.0-USB声源方向-前方校准.apk`，覆盖已有版本。原来的画面、字幕和遥控设置继续保留。
2. 用支持数据传输和 OTG 的转接头 / 数据线连接手机和小板。若手机系统要求，开启其 OTG 功能。此连接使用手机 USB 主机模式，不需要开启 USB 调试。
3. 打开听见视界，进入 **手机自定义设置 → 深层设置 → USB 声源方向与前方校准**。
4. 点“刷新 USB 列表”，选择 `1A86:7523` 对应的设备，保持 **115200 / 自动**，点“连接 / 授权”，允许系统 USB 访问提示。
5. 在小板附近发声。先确认“收到字节”增加，再确认“有效”记录增加，并看到类似“原始 354.0° → 正前方 354.0°”的角度信息。接通后可能先出现启动日志，等待其进入正常输出。
6. 固定小板相对于头部 / 手机的安装位置。在你认为的正前方放置声源并发声，收到有效读数后点 **把当前有效方向设为正前方**。也可以手工填写正前方对应的原始角度，再点“应用参数并保存”。
7. 将声源移到右侧检查结果。若方向左右相反，切换“顺时针 / 逆时针”并保存。再依次核对前、右、后、左。没有独立姿态传感器时，小板必须与头部保持固定朝向；改变安装位置或转动小板后应重新校准。
8. 关闭设置，进入双眼观看。画面上方显示方向箭头、方位和相对角度；左右眼与电脑无线接收使用相同提示。拔掉小板或停止更新后，旧箭头应清除，显示未连接或信号过期。

步骤 5 中的方位示例应以实际前方基准为准；原始 354°、前方基准 0° 时按八方位划分为正前方。本版本的标签按 45° 分区，零点附近两侧都属于正前方。

## 可调整项目

| 项目 | 作用 |
| --- | --- |
| 波特率 | 9600–921600 中的常用档位；本块小板已确认使用 115200 |
| 数据格式 | 自动、带 angle 标签文本、JSON、每行仅数字、只读原始数据 |
| 正前方对应角度 | 0–360°；360° 等同 0°，保存为 0° |
| 顺时针 / 逆时针 | 解释原始角度增大时绕哪一方向旋转 |
| 超时 | 0.5 / 1 / 2 / 3 / 5 / 10 秒；默认 3 秒无新角度即失效 |
| 画面方向提示 | 控制手机普通预览、左右眼及无线画面上的方向显示 |
| 最近原始文本 / HEX | 排查收到启动日志、乱码、二进制或未支持的格式；只在内存显示，不保存文件 |

顺时针模式：`相对角度 = (原始角度 − 前方基准 + 360) % 360`。逆时针模式使用反向差值。输出统一为 **0° 前、90° 右、180° 后、270° 左**。例如基准 355°、原始 1°，相对角度是 6°，不会变成 −354°。

## 信号与连接状态

- “串口已连接”只说明 USB 通路打开，不表示方向定位有效。只有成功解析的新记录才刷新方向时间。
- 自动格式不接受无标签数字，不会把 ESP32 启动信息中的数字当角度。未知行会增加忽略计数；错误角度不会变为 0°。
- 拔线、关闭读取、应用进入后台会立即使角度失效。回到前台时，只尝试恢复你已选择的小板；系统撤销 USB 授权时需再次点连接。
- 重新连接 / 修改波特率或格式会清空本次连接的计数及原始记录。正前方、方向解释和显示选项继续保存。
- 如只收到启动日志或乱码：先核对 115200 / 8N1，并检查小板是否正常运行。不要为了“有角度”而选择数字模式解析启动日志。
- 如果没有设备列表，先检查 OTG、数据线和供电。程序不会主动申请访问鼠标、键盘或存储设备。

本接口反映小板报告的水平角度，不据此判断声源距离、高度、声音种类或具体说话人，也不承诺小板对多声源与反射声的定位精度。

## 软件接口

见 [USB 方向接口协议](USB方向接口协议.md)。未来电脑程序可在原有授权的 `GET /status` 中读取 `stereo.direction`；USB 原始数据不会通过这个状态接口暴露。未提供网络模拟角度或网络写入小板的接口。

参考：[Android USB 主机与设备授权](https://developer.android.com/develop/connectivity/usb/host)、[usb-serial-for-android 驱动项目](https://github.com/mik3y/usb-serial-for-android)。手机供电、授权与小板实际定位效果需在直连实物后验证。
