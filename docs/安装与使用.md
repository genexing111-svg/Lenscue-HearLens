# 听见视界：安装与使用

这是“AI 眼镜辅助听障人士”项目的第一阶段摄像头测试版，版本为 **0.1.0**，应用包名为 `com.hearlens.app`。交付的 `dist/HearLens-0.1.0-debug.apk` 是已签名的个人测试安装包，不是应用商店发布版。

## 先了解这次能做什么

手机摄像头负责取景，手机屏幕显示实时画面；现在不需要购买或连接眼镜。应用提供后置/前置摄像头切换、暂停/继续、相机状态和故障提示，支持横竖屏。

本版只做预览，不拍照、不录像、不保存影像。它离线运行，只申请摄像头权限，不申请麦克风、存储或联网权限。人物头顶字幕、语音识别、环境声分类和方向提示尚未实现，界面不会显示模拟字幕。

适配目标是红米 K80 Pro、HyperOS 3.0.304.0。HyperOS 版本与 Android 版本不是同一个信息；请以手机实际显示的 Android 版本及应用诊断信息为准。

2026-09-21 已在该手机上完成 ADB 安装、启动及相机授权状态检查，实测 Android 16 / API 36，应用 UI 显示“后置摄像头 · 预览中”。真实画面和按钮功能仍需在手机上验证；详细证据与限制见《构建与测试报告》。

## 安装到手机

1. 在电脑中找到本项目交付目录中的 `HearLens-0.1.0-debug.apk`。请使用这个项目生成的文件，不要从陌生网页下载同名安装包。
2. 用支持数据传输的 USB 线连接电脑和手机，解锁手机。按手机的 USB 提示选择文件传输，将 APK 复制到手机的下载文件夹或另一个容易找到的位置。
3. 在手机的文件管理器中找到 APK 并打开。如果系统要求允许该文件管理器安装应用，按页面提示开启对应来源的安装权限，再返回安装页面。
4. 按系统提示完成安装，然后打开“听见视界”。普通 APK 安装不需要开发者模式或 USB 调试。
5. 首次进入时阅读摄像头用途说明，点击授权入口，并在系统权限弹窗中允许使用摄像头。授权后应看到后置摄像头实时画面。

HyperOS 的提示文字和设置入口可能随版本变化，因此以上不写死菜单名称。保持系统安全检查开启；若系统阻止安装，记录页面的准确提示，以便判断原因，不要关闭整机安全检查。

如果电脑无法显示手机存储，先检查手机是否已解锁、USB 是否选择文件传输，以及线缆是否支持数据。也可以用你已有的文件传输方式复制这个本地 APK，再在手机上打开。

## 日常操作

| 操作 | 预期效果 |
| --- | --- |
| 打开应用并授权 | 显示后置摄像头画面和当前相机状态 |
| 点击切换前后摄像头 | 在前置与后置摄像头之间切换；本版不提供长焦、超广角镜头选择 |
| 点击暂停 | 停止取景，界面显示暂停状态 |
| 点击继续 | 重新打开摄像头并恢复实时画面 |
| 转动手机 | 界面适应横屏或竖屏，按钮保持可操作 |
| 切到其他应用或锁屏 | 停止取景，不在后台持续使用相机 |
| 返回应用或解锁 | 检查权限后恢复取景；若此前手动暂停，应继续保持暂停 |

授权时如果选择了仅本次允许，系统之后可能再次询问权限，这是系统权限行为。应用不能绕过你的权限选择。

## 遇到问题时

| 情况 | 处理方法 |
| --- | --- |
| 拒绝了摄像头权限 | 使用应用中的授权或重试入口；如系统不再弹出权限对话框，从该应用的系统设置页面恢复摄像头权限，再返回应用 |
| 画面黑屏或提示相机不可用 | 确认摄像头未被遮挡、系统的摄像头访问开关已开启，再点击重试 |
| 相机可能被其他应用占用 | 退出其他正在使用相机的应用，返回“听见视界”后重试 |
| 相机初始化失败 | 记录界面错误和触发步骤，退出后重新打开；仍失败时保留信息用于排查 |
| APK 无法安装 | 记录系统完整提示，确认 APK 已完整复制并来自本项目；不要仅凭“安装失败”推断为设备不支持 |
| 后续版本提示签名冲突 | 停止安装并记录提示，确认使用的是同一项目交付的新版本；不要为排错随意卸载其他应用 |

反馈时请提供手机型号、HyperOS 版本、实际 Android 版本、应用版本、错误文字和复现步骤。只有在问题确实涉及画面时才需要截图，并先确认截图中没有你不想分享的人或内容。

## 后续怎么走向眼镜

摄像头基础版验收后，按阶段加入人物跟踪和气泡位置、真实语音字幕、多人说话对应、环境声分类，再验证声音方向，最后连接眼镜显示与空间定位。

识别“泼水声”与判断“右后方”是两项不同能力。声音方向阶段需要先实测手机可取得的音频通道及定位效果，再决定是否增加同步麦克风阵列；不能仅凭手机内置多个麦克风就保证准确方位。本阶段不申请麦克风权限，也不做这项判断。
