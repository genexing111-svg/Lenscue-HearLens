# v0.14.1 · 环境音辉光连续图传修复

此版修复“环境音辉光出现后，电脑显示已连接但收不到新画面”，并修复电脑单眼画面只显示局部的问题。手机端版本为 0.14.1 / 28，电脑接收端 1.0.2，原有控制接口兼容。

## 电脑单眼显示修复（2026-10-12）

单眼模式的画布固有宽高会影响 CSS Grid 的行高：原先约 531 px 的容器被撑出约 1330 px 的画布，超出部分遭裁切。现将视频画布定位在容器内部，固定边界并等比例居中显示，单眼标签也居中。左右眼在普通窗口、全屏及窄窗口中均保持完整画面。

电脑端已更新，现有浏览器按 Ctrl+R 刷新即可；仍看到旧版时用 Ctrl+F5 强制刷新。此次显示修复不需要再次安装手机。单眼画面包含手机原本的眼距和缩放留白；等比例显示可能出现黑边，这是完整显示的正常结果。

## 原因和改动

手机本地使用 GPU 绘制辉光；无线视频则在独立线程将相同内容合成为 JPEG。旧版本在方向角变化时，会为每个像素重新计算三角函数、指数函数并创建数组，精确角度缓存很难命中。现场日志记录到单帧合成耗时 2015–3159 ms，超过 1500 ms 的新鲜度上限，因而被丢弃。连接和手机本地显示仍正常。

新版缓存几何映射、边缘光强与方向扩散表，改变方位时通过表格计算像素，不再逐像素重复高成本计算。辉光仍显示在双眼和电脑视频中。视频分辨率、JPEG 质量、手机显示分辨率和用户设置均保留；没有放宽旧帧的超时限制。

## 使用

1. 安装 `听见视界-v0.14.1-环境音辉光连续图传修复.apk`，覆盖原应用即可保留数据。
2. 手机打开听见视界，开启无线共享并进入双眼观看；与电脑保持同一局域网。
3. 电脑双击桌面“听见视界-电脑接收端”，或打开 <http://127.0.0.1:18780/>。
4. 小板接回手机并开启环境音感知。辉光、环境音标签、字幕与双眼画面一并传输。

完整控制台操作见随包的“完整控制台使用说明”。该文档基于 v0.14.0，界面和接口延续；本包安装入口使用 v0.14.1。

## 回滚

旧版 APK 与源码保存在 `dist/rollback/v0.14.0-before-glow-stream-fix/`，原 `dist/0.14.0-Desktop-Console/` 交付目录也保留。手机允许测试包降级时，可用 `adb install -r -d` 安装旧版 APK；若系统拒绝，不要自动卸载或清除数据。回滚会恢复旧版的辉光图传性能问题。
