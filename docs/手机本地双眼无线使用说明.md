# 听见视界 v0.5.1：手机本地双眼 + Wi-Fi 共享

适用目标：vivo S30（本次连接型号 V2464A，实际 Android 16 / API 36，屏幕 1080×2400）。是否开放超广角、长焦由手机系统相机接口决定；应用读取实际镜头列表，不照搬红米的镜头编号。

## 安装和观看

1. 将 `听见视界-v0.5.1-手机原生高清双眼-WiFi字幕-镜头自定义.apk` 复制到手机，用文件管理器打开安装。按 vivo 提示允许本次安装。普通安装无需 USB 调试。
2. 打开“听见视界·高清本地双眼无线版”，允许使用相机。此版只持续实时取景，不保存视频、不录音。
3. 点“进入双眼观看”。手机自动横屏，在手机本地生成左右眼画面，电脑和网络都不是本地观看的前提。
4. 轻触双眼画面，出现“手机自定义设置”和退出按钮。镜头夹持时不要遮挡摄像头。左右眼是同一镜头完整画面的等比副本，没有真实立体深度。
5. 暂停、锁屏、切到其他应用会停止采集和共享；回到应用后恢复。使用时保持本应用在前台。

## 电脑无线连接

1. 手机和电脑连接同一个可互通的 Wi-Fi，或电脑连接手机热点。公司、校园、访客 Wi-Fi 可能隔离设备，即使 Wi-Fi 名称相同也不能互访；此时优先使用手机热点。
2. 开启手机上的“无线共享”。点击连接状态区域，或从“手机自定义设置 → 无线连接地址”复制完整链接。
3. 在电脑浏览器粘贴完整链接，包括 `#` 及后面的访问密钥。地址示例：`http://手机局域网IP:18766/#访问密钥`。无需电脑版程序、USB、ADB、云服务或账号。
4. 电脑显示手机已经合成的双眼画面。在右侧输入文字并点“发送字幕”，文字会在手机左右眼同时出现；电脑接收的画面也包含该文字。
5. 网络暂时中断时电脑自动重连，旧画面会清除。手机本地继续生成画面。更换 Wi-Fi / 热点可能改变 IP，请重新复制链接。

链接带访问密钥，只提供给需要观看的人。服务使用局域网 HTTP，适合可信家庭 Wi-Fi / 自己的热点；不是公网视频服务。关闭手机无线共享即可停止访问。电脑上的旧 USB 启动器属于 v0.4，请使用新版手机显示的链接。

## 手机自定义设置

| 设置页 | 可调项目 |
| --- | --- |
| 镜头与相机参数 | 系统实际开放的镜头、采集目标帧率、采集尺寸档、缩放、曝光补偿、补光灯、中心对焦/测光 |
| 双眼位置与缩放 | 整体缩放、双眼间距、左右眼独立尺寸/上下位置、单眼查看、十字/网格校准 |
| 画面颜色与方向 | 软件亮度、对比度、饱和度、附加旋转、水平镜像 |
| 文字与字幕 | 最多 120 字、字号、位置、颜色、对齐、底色透明度、描边 |
| 清晰度与无线帧率 | 无线双眼总宽度、无线最高帧率、无线 JPEG 质量 |
| 观看预设 | 高清流畅、最高采集清晰度、大字舒适、恢复默认 |

初始高清流畅设置：采集尺寸档 1280，自动选择当前相机组合支持的最高普通帧率；无线独立使用总宽 960、最高 15 fps、JPEG 质量 60。可在“最高采集清晰度”预设选择 1920 档。实际采集尺寸以状态为准，不一定等于请求值。无线总宽不影响手机原生分辨率。两眼各自保留完整画面，比例不同的部分留黑边。

优先在手机采集设置选 1920 / 自动帧率；若实际手机显示帧率下降，可降为 1280。无线卡顿时，单独将无线质量降到 45、无线帧率降到 10 或无线总宽降到 640。采集与合成也受手机性能、镜头能力和温度影响；设置数值是目标或上限，不是承诺每帧都达到。电脑状态分别显示本地输入、手机实际显示、电脑接收帧率。

手机使用屏幕原生分辨率硬件绘制双眼（vivo S30 横屏总画布 2400×1080，每眼区域 1200×1080），镜头帧无需经过 JPEG。无线编码单独运行，降低无线清晰度不降低手机显示分辨率。

画面布局自动保存到手机；手动字幕仅在当前应用会话中保留，不保存字幕历史。镜头/帧率/采集尺寸设置保留；补光灯每次相机停止时关闭。改变镜头或采集参数需要短暂重新连接相机。

电脑控制台仍能调整这些项目。打开后的表单保留正在编辑的值；若在手机改了参数，可刷新电脑页面以重新加载当前值。

## 与前一版的差别

v0.4 是“手机取景 → USB 发电脑 → 电脑合成 → USB 回手机”。v0.5 是“手机取景并合成 → 手机显示，同时 Wi-Fi 发电脑”；电脑只将文字/控制参数发给手机。电脑断开不会使手机双眼观看退出。

本版未加入自动语音识别、人物追踪、环境声识别、空间定位或视频文件录制。字幕接口为后续电脑语音识别预留，见 `无线字幕接口.md`。

G05 Pro 的瞳距调节、软件字号及画面缩放不提供屈光矫正。沿用旧版 `近视与眼镜调节.md` 的说明；需要适合的屈光矫正或具备适当调焦范围的光学方案。
