# v0.11.1：声源左右校准

针对声源左右反向，增加直接互换和侧向声源采样两种校准方法。两种方法都只改变小板角度增大的方向解释，**不会移动已经保存的正前方基准**。相机、字幕、双眼、无线和遥控设置保留。

入口：**手机自定义设置 → 深层设置 → USB 声源方向与左右校准**。校准按钮位于页面下部，在“把当前有效方向设为正前方”下面，需向下滑动。

## 只需要纠正左右颠倒

点击 **一键左右互换（立即保存）**。不需要正在接收小板数据，立即生效并保存；再次点击可以恢复。右方与左方、右前方与左前方、右后方与左后方对调，正前方和正后方保持不变。

若之后再点“应用参数并保存”，页面的顺逆时针选项已同步更新，不会意外覆盖刚才的互换结果。

## 用真实声源校准

1. 将小板通过 OTG 连接手机并允许访问，保持小板与头部 / 手机的安装位置固定。
2. 先在正前方发声，用原有“把当前有效方向设为正前方”保存基准；已经确认前方正确时可以保留原值。
3. 将声源放在**正右侧**（不是前后方），点 **声源在右侧：开始 4 秒校准**，持续发声 4 秒，手机会显示倒计时和采样数量。也可使用左侧按钮、在正左侧发声。
4. 看到“校准已保存”后，在另一侧发声核对。重复执行正确的同侧校准不会反复翻转方向。
5. 如果提示读数不足、角度跳动或接近前后方，本次不会更改已有设置。固定声源、减少其他声音并确认前方基准后重试。

采样期间，波特率、基准角度等参数暂不可修改；可以点“取消本次左右校准”、关闭设置或断开。中途取消不保存。系统断线、串口重连或基准变化也会让本次校准失效。

## 判断规则

仅使用按下按钮后收到的新记录，至少 3 个不同接收时间点，且跨度至少 1 秒。使用圆周均值处理 359° / 0° 跨界；离散程度过大或任一采样偏离均值超过 25° 时拒绝保存。相对前方的原始角差应在 45°–135° 或 225°–315°，否则难以可靠区分左右。

本功能校准的是**左右对应关系**，没有将实测角度强行拉到 90° / 270°，不能修复小板定位算法本身的角度偏差、前后混淆或多声源干扰。若左右已正确、角度仍明显不准，需要继续检查小板固定方式和真实输出。

USB 参数保持 115200 / 8N1，默认自动解析 `angle: N.0 deg`。串口接入和状态 API 见 [USB 方向接口协议](USB方向接口协议.md)。
