# 听见视界 v0.7.0：麦克风、语音 API、返回字段（待真机测试）

本轮按用户安排只制作待测试版本。没有启动手机麦克风、录制真人语音或调用真实云端模型；没有开放或修改原语音后端，也没有将模拟结果当作识别结果。

## 入口与使用步骤

1. 安装 `听见视界-v0.7.0-麦克风-语音API-字段回显-待测试.apk`，同一测试签名，可覆盖 v0.6.2，保留已有相机、双眼布局与遥控校准。
2. 普通相机页面点击 **语音接口测试（待验证）**。本阶段为独立调试页面，进入时相机 / 视频共享暂停；返回相机页恢复原有功能。
3. 填写手机可访问的后端 HTTP 地址；WebSocket 地址可单独填写，留空时从 HTTP 地址推导。支持路径前缀，例如 `https://example.com/bridge/` 会请求 `/bridge/api/config` 与 `/bridge/stream`。
4. 如果后端使用 Bearer 连接鉴权，可填“后端访问令牌”。该值只存于当前页面内存，不保存到配置文件；**不要填写阿里云长期 API Key**。HTTP / WS 只允许局域网 IP、回环或 `.local` 地址；公网使用 HTTPS / WSS，保留默认 TLS 证书校验，禁止跨地址重定向。
5. 先点 **检查接口（不录音）**。查看 `/api/config` 中的 `configured`、`engines`、`frameMs`。`configured=true` 只表示后端配置了密钥，不代表鉴权已经成功。
6. 选择“快速转写 asr”或“同声传译 live”；live 可选 `en` / `zh`。授予麦克风权限后，仍需手动再点 **开始语音测试**。只有收到后端 `ready` 后才启动手机麦克风。
7. 观察电平、输入格式、上传包数 / 字节数、实际 `ready.model`、原文 / 译文字段及 JSON。点击 **停止采集并等待最终字段**，待收到 `finished`；紧急停止可点“立即取消”。

切换模式或目标语言前先停止当前会话；结束后重新选择并开始。双眼字幕仍使用原来的手动文字功能，本轮语音返回仅显示在调试页面，不叠加字幕。

## 返回内容

- `ready`：实际 `engine`、`model`、`frameMs`、可选 `target` 等。
- `result`：完整 `sentence`，包括 `sentence_id`、`text`、`sentence_end`、时间和可选 `words`。
- `segment`：完整 `id`、`speakerId`、`original`、`originalFinal`、`translations`、`translationFinal` 和时间字段。`speakerId="0"` 保留，不等同未知；编号不表示真实人物身份。
- `configured`、`restart_required`、`error`、`finished` 等协议消息单独显示。

同一编号的句子 / 句段以新快照替换旧内容，不重复拼接全文。最近 12 条摘要、最近一条数据 JSON 和协议消息保存在页面内存；长字段限长展示，不创建录音文件、字幕历史或自动日志。后续字幕 UI 可从 `SpeechSnapshot` 接入，当前相机与双眼渲染不消费这些返回字段。

## 音频与连接行为

- Android AudioRecord 请求 **16000 Hz / 单声道 / PCM16**，优先选择并核验手机内置麦克风。若设备不能提供该格式则报错，不假装已重采样；本机实测留待用户返回后进行。
- 以读取到的 Short 样本显式编码为 **PCM16LE**；普通包 **640 字节 / 320 样本 / 20 ms**，无 WAV 头、无 Base64、无 JSON 音频包装。
- 停止次序为：停止采集 → 非空偶数字节尾包 → `{"type":"stop"}` → 等待最终数据与 `finished` → 关闭连接。
- 配置请求超时 10 秒，等待 ready 20 秒；停止后 ASR 最多等 10 秒、同传最多等 18 秒。异常会释放麦克风并中止连接，不自动重新录音或重发旧音频。
- 发送队列超过约 1 秒 PCM 数据时停止，避免积压。禁止重复开始；配置 / 模式在会话中锁定；旧会话回调不能写入新会话。
- 锁屏、离开测试页或切到后台会立即取消连接和采集，尾句可能不完整。返回后需手动重新开始。此阶段不提供后台常驻录音。

## 后端联调尚需提供

交接包给出的是**自建语音后端协议**，不是手机直连阿里云的原始接口。链路为：手机采集与请求 → 指定语音后端 → 云端模型 → 返回字段到手机。

参考服务仅监听电脑 `127.0.0.1:8765`，同时限制 Host / Origin；把地址改为电脑 IP 不足以开放手机访问。准备本版时该端口未检测到可用配置接口。无线联调需要后端提供手机可达地址、相应监听 / Host / Origin 配置与访问鉴权；密钥继续留在后端，不打入 APK。原有视频无线功能与这个语音后端地址无关。

后续也可在用户接回 USB 后，按实际后端部署使用 ADB reverse 做**有线开发联调**；这不是无线接入完成。本轮没有开启该映射或启动参考服务。

## 用户返回后的待测项目

1. 拒绝、重新授权与系统麦克风开关关闭的提示；电平与内置麦克风路由。
2. 实际后端配置、云端鉴权，ASR 普通话语音的临时及最终 `result`。
3. live 原文、中文 / 英文译文及匿名说话人字段；不预先承诺粤语、混说或说话人区分准确率。
4. 停止后尾句、`finished`、系统麦克风指示关闭；断网、后台、锁屏与快速重复点击。
5. 回到相机页后的取景、无线共享与遥控菜单回归。
