# 听见视界 v0.10.0 · 两层设置、镜头轮盘与语言滑块

## 设置界面

普通画面点“手机自定义设置”或“实时语音字幕 / 设置”。双眼观看时按 X，或轻触画面。两处使用同一份设置数据：暖灰半透明圆角面板、深色分组、白字、绿色开关和带刻度的滑块。

常用页只有五项：实时字幕、字幕语言、使用镜头、双眼观看、深层设置。

深层页保留手机分辨率与帧率、相机采集参数、变焦、曝光、补光、对焦、整体和左右眼单独大小/位置、颜色、旋转、镜像、语音字幕宽度/位置/字号/材质、手动文字、无线质量、观看预设、连接地址、遥控器学习、语音状态与接口测试。前置摄像头仍可在“使用镜头”选择。

手机滑块拖动时显示所选档位，松开应用。双眼菜单用摇杆上下选择、左右调整；镜头、字幕语言和相机采集参数要按 A 应用，B 取消未确认的选择。数值参数直接预览；绿色开关右拨开启、左拨关闭，A 切换。X 关闭整个菜单，B 从深层返回常用页。

## 五档字幕语言

从左到右固定排列：

| 档位 | 内容与服务 |
|---|---|
| 快速识别 | ASR 流式转写的原文，不虚构说话人编号 |
| 说话人识别 | 同传模型返回的原文及说话人编号 |
| 转译为简体中文 | 同传模型中文译文，手机进行简体字形转换 |
| 转译为繁体中文 | 同传模型中文译文，手机进行繁体字形转换 |
| 转译为英文 | 同传模型英文译文 |

改变档位不会自动开启麦克风。字幕关闭时只保存选择；字幕开启时，若需要更换服务/目标语言，会停止采集、等待尾句结束，再连接新模式，中间可能短暂没有新字幕。连接异常会保留错误，需手动重开，不无限重试。简繁之间使用同一中文会话；原文与英文之间使用同一英文目标的同传会话，不重连。

简繁转换使用 Android ICU（Android 10 及以上；K80 Pro 当前 Android 16 支持），属于字形转换，并非不同地区词汇的人工本地化。原有最多四行、云端说话人改变另起行的字幕规则保留。识别准确率与说话人分离效果取决于真实音频和模型结果。

## 遥控快捷操作

**肩键镜头轮盘**：按住肩键呼出圆环。向上指主摄、右下指长焦、左下指超广角；选中后松开肩键切换。摇杆回中再松开取消，B 也可取消。没有开放对应镜头的设备会显示不可用，不用数码裁切冒充另一颗镜头。两眼各自绘制同样大小、对应位置的轮盘。

**@ 字幕语言滑块**：短按 @，在每只眼视野右下方呼出五档滑块；摇杆左右选择，A 确定，B 退出。停在某一档只是预选，按 B 后原模式和会话保持不变。再次按 @ 关闭。两端不会循环跳转。

默认支持 Android 标准肩键 L1/R1/L2/R2、模拟扳机及 AT/MODE/SELECT；SC-B03 的 ENTER/播放键也作为肩键候选。实体字母和系统键码可能不同，升级保留已经完成的 A/X/B/Y 校准。**长按 X 约 0.65 秒也可打开字幕语言滑块**，短按 X 仍是菜单；这是 @ 不上报时的备用入口。

如果肩键或 @ 没反应：在“深层设置 → 遥控器与快捷键 → 学习单个按键映射”，分别选择“按住呼出镜头轮盘”和“字幕语言滑块”，再按对应实体键。要使用可发出按下、松开事件的肩键。学习会替换该物理键原有绑定。

SC-B03 的 @ 同时用于遥控器硬件模式切换（见 [厂家说明书内容](https://manuals.plus/vr-shinecon/2atps-sc-b03sc-b03-wireless-bluetooth-gamepad-black-manual)）；是否向 Android 单独发出事件，须以这一只遥控器实测为准。如果手机没有收到该键，应用无法凭空检测，可用长按 X，或将“字幕语言滑块”学习到另一枚能上报的键。不要为此长按电源键。

退出应用、断开遥控器、失去窗口焦点时取消未确认快捷选择，避免回来时误切镜头。手机单摄画面复制到双眼，不宣称双目立体摄像。

## 安装和保留数据

安装包：`听见视界-v0.10.0-两层设置-三镜头轮盘-五档字幕语言.apk`。同签名覆盖安装即可，不要先卸载。相机参数、双眼校准、遥控器四键映射与本机加密保存的语音凭据继续使用；旧“原文/中文/英文”选择迁移到对应新档位。

普通安装只需传 APK 到手机后打开，不需要 USB 调试。开发验证使用 ADB。源码与安装包不包含个人 API Key。电脑无线视频接口保持原样。

构建：`scripts/build.ps1 assembleDebug lintDebug testDebugUnitTest`。交付打包：`scripts/package-glass-settings.ps1`。当前构建要求与上一版相同。
