日期：2026-10-10。目标真机：已连接的红米 K80 Pro（24122RKC7C），实际 Android 16。应用版本 0.12.0，versionCode 20。

## 交接与移植

- 环境音包 MANIFEST 的 139 个文件 SHA-256 全部匹配；视觉包 SHA256SUMS 的 49 个文件全部匹配。

- 覆盖无有效方位、角度分歧、事件去重 / 过期 / 3 个上限、字幕避让、共享麦克风独立启停和关闭过程重新订阅。

## 真机原生测试

- v0.12.0 已覆盖安装；麦克风权限沿用用户此前授予的状态。
- 真机 CPU 静音窗口最高类为 Silence（494），分数 0.80078125；指定公开语音窗口最高类为 Speech（0），分数 0.95703125，与交接观测一致。
- 最近一次 20 次公开窗口推理平均约 1.58 ms；这是模型调用耗时，不包含 975 ms 音频窗口、连续确认、采集、视频与网络延迟。
- 原生 GPU / 软件两条渲染路径均输出偏暗、偏白、纯白场景的右方与右后方光晕；测试末尾 2800 ms 无残留。双眼双事件输出已生成。
- 横竖屏设置离屏图已通过生产绘制代码在手机生成并目视核对：横屏左侧文字，右侧模式条；蓝色开关使用正常胶囊比例；竖屏保持上下排列。
- 以上图像是设计背景驱动的真实手机渲染结果，不是手机摄像头截图或真实声源检测结果。没有将演示事件打入生产功能。
- 安装前读到用户当前方向基准为 95°、逆时针，后续升级保留，未恢复旧的 186° 或默认顺时针。

初次图形检查因测试只绘制一次、未按真实帧循环继续请求异步背景材质而超时；改为按帧等待后通过。另修正了跨参考场景核对时必须等待对应场景材质的问题，并限制运行中使用过旧的材质。未以旧场景缓存图作为最终验证图。
