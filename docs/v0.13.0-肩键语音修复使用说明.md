# v0.13.0：按住说话、松开播放

## 操作

1. 在普通预览或双眼观看界面，**按住肩键**。中央出现语音胶囊；看到“正在收音”或“松开播放”后说话。
2. 按住期间显示实时识别原文。左侧使用提供的 `person-speaking.svg`，右侧蓝紫渐变条反映声音强弱，安静时为七个圆点。
3. **松开肩键**结束收音。应用先保留尾包并等待麦克风实际停止，再播放生成语音；按住期间即使云端已返回音频，也不会播放。
4. 播放时可显示重述 / 翻译文字，播完后胶囊自动收起。下一轮请等本轮播完再按住。

胶囊沿用字幕的半透明暖灰蒙板。短句使胶囊横向增长，到达约每眼画面 90% 宽度后换行，左右图示始终垂直居中。最多显示最近六行，完整本轮文字保留在会话内存中，不影响完整音频播放。

首次缺少麦克风权限时，按系统提示允许，然后重新按住肩键；授权完成不会自动开始一次无人按住的录音。Key 继续读取手机原有加密配置，普通使用无需再填一遍。

## 镜头与其他设置

- 镜头轮盘已移除，肩键专用于语音修复。
- **浅层设置 → 使用镜头**，用统一的多档滑块选主摄、超广角、长焦或前置等系统可用镜头；遥控器摇杆左右选择、A 确认。
- 新增浅层 **语音修复输出** 滑块：默认“中文重述”，可选“英文翻译”，对下一轮生效。
- X 的字幕语言小窗、Y 的环境音感知快捷开关、后方声音贴边与字幕避让继续保留。
- 本轮收音和播放期间，常驻字幕、环境音处理和方向光晕暂时让位；播完后恢复之前开启的功能。期间用 Y 关闭环境音，则播完也保持关闭。

## 结束与中断

- 单次最多收音 30 秒；达到上限停止收音，提示松开，仍等实际松手后才播放。
- 太快松开、麦克风尚未就绪时取消本轮，不会稍后自动开始录音。
- 锁屏、切换应用、窗口失去焦点或遥控器断连时取消本轮，停止待播和正在播放的音频。手机端不在后台继续播报。
- 连接或生成失败时显示原因、清除本轮队列，可重新按住重试；不自动重复上传或重播。
- 播放使用系统媒体音量和当前媒体输出设备；没有声音时先检查媒体音量及蓝牙耳机路由。

## 模型与验证含义

使用交接包的北京 `qwen3.8-livetranslate-flash-realtime`，请求文本 + 音频及本轮音色复刻。已配置的业务空间优先使用，空白时采用交接包已验证的业务空间；不改变原有常驻字幕的 Tina 文本配置。

音频在按住期间发送到阿里云，生成音频只在内存中排队；不自动保存录音或音频文件。中文重述可能调整措辞，实际体验请确认原意、清晰度与音色是否合适。

协议依据用户交接包，相关参数同时核对了[阿里云客户端事件文档](https://help.aliyun.com/zh/model-studio/live-translator-client-events)。SVG 原件及许可随 APK 和源码一同保留。

## 安装与回滚

本版安装包与源码位于 `dist/0.13.0-Shoulder-PTT-Capsule/`。

修改前 v0.12.4 的 APK、源码与校验值完整保存在 `dist/rollback/v0.12.4-before-ptt/`，附 `回滚到v0.12.4.ps1`。此前 v0.12.3、v0.12.2 备份继续保留。

需要回滚时，有线连接手机并允许 USB 调试，运行对应脚本；脚本核对 APK 哈希，用 `adb install -r -d` 尝试保留数据回滚。系统拒绝时停止，不会自动卸载或清除数据。本轮没有实际执行降级。
