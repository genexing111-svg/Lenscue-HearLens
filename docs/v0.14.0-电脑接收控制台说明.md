# 听见视界电脑接收控制台 v1.0

日期：2026-10-11。配套手机端：v0.14.0。电脑程序已在本机运行，访问 **http://127.0.0.1:18780/**。

## 直接启动

桌面“听见视界-电脑接收端”快捷方式，或 `desktop/receiver/启动电脑接收端.cmd`，可启动服务并打开控制台。重复运行会复用已有服务。

服务进程隐藏运行，关闭浏览器不等于停止服务。要退出，使用“停止电脑接收端.cmd”。没有添加开机启动项或 Windows 计划任务；重启电脑后再次双击启动即可。

本电脑使用已有 Node.js v24.19.0，无新增 npm 依赖；换电脑需安装 Node.js 22 或更新版本。启动器直接运行 Node，不要求更改 PowerShell 执行策略。

## 接入手机

1. 手机与电脑连接可互通的同一 Wi-Fi / 手机热点。手机打开听见视界并保持在前台，开启无线共享。
2. 在电脑连接页粘贴手机完整观看链接（含 `#` 后的访问密钥）。也可以 USB 连接、解锁并授权调试后，点“通过 USB 读取连接”。
3. 本机服务会在未连接时尝试识别唯一已授权的 USB 手机，读取本 App 的无线访问令牌和 Wi-Fi 地址。此过程不读取语音模型 API Key，也不自动安装 APK或开启麦克风。
4. 视频仍由手机通过局域网发送；USB 自动读取连接信息不代表 USB 视频模式。

电脑断开后会自动重连已配置的手机。地址变化时，USB 仍连接可重新识别；否则重新粘贴手机的新链接。主动“断开电脑”会暂停本次自动发现。

观看链接用 Windows 当前用户的 DPAPI 加密保存在 `.runtime/connection.json`。该配置不进入交付 ZIP，也不把令牌放进浏览器地址或日志。新控制台只监听电脑回环地址，未开放外网或修改防火墙。

分组参数需点击“应用到手机”。手机端改动会同步回读；电脑未提交的草稿不会被轮询覆盖，提交后等待实际值匹配再标记同步。连接时不自动应用预设或重置参数。

点击“手机无线共享”关闭后，手机将停止监听，须在手机重新开启才能恢复电脑控制。系统相机、麦克风和 USB 权限仍由手机授权，控制台不能跳过系统提示。

## 视频与语音重构

- 主画面展示手机最终合成的双眼 JPEG，包括手机字幕和提示；可仅看左眼 / 右眼或全屏。单眼查看仅改变电脑显示。
- 多个电脑页面共用一条上行视频读取循环，不再为每个页面创建手机视频连接。帧过期时清除旧图，不把定格画面显示成直播。
- “手机显示”取手机双眼绘制帧率；“电脑接收”按最近 3 秒接收新帧统计；“画面时效”是手机帧发布年龄加本机缓存时间，不是摄像头到屏幕的完整端到端延迟。
- 电脑按住说话调用手机麦克风，松开后仍由手机当前媒体设备播放。浏览器不申请电脑麦克风权限。
- 按住期间需续期。页面失焦 / 隐藏会取消；网络中断导致约 3 秒收不到续期时，手机取消本轮，防止漏掉松开事件而持续收音。
- 原有已识别字幕保留、顶部胶囊、环境音临时隐藏及播放后恢复规则继续保留。

## 手机版本与本次验证边界

旧版 v0.13.1 提供视频、镜头、画面和手动文字接口，电脑可兼容连接这些功能。**全部高级设置需要安装本次配套 v0.14.0 APK**；旧版不支持的选项会禁用，并提示升级。

v0.14.0 已通过 USB 覆盖安装到红米 K80 Pro，并完成同网连接。电脑已收到 960 × 432 的真实双眼画面，接收约 15 fps；字幕字号修改经手机端保存值确认后已恢复原值。接收服务重启后也已从加密配置自动恢复连接。小板校准、远程 PTT 等其他控制尚未逐项真机验收。

已完成电脑协议测试、浏览器隔离接口测试、加密存储和启动器检查。隔离测试使用明确标记的固定素材，测试服务已关闭；正式控制台当前连接真实手机，没有混用测试画面。
