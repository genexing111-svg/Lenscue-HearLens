# v0.12.2 验证记录

日期：2026-10-10；目标手机：红米 K80 Pro / Android 16。包名 `com.hearlens.app`，versionCode 22。

## 实现

- 浅层“声音感知”使用生产 `SettingsSwitch` 与双眼 `SettingsPainter.toggle`，和其他开关同样的蓝色与圆润比例。
- 开关与详情入口分别处理：右侧切换、左侧名称查看设置；保留遥控器的显式开 / 关与深层详情入口。
- 功能关闭改为 `pausePerception`：清除有效角度 / 历史，停止分类，前台串口继续就绪并丢弃未启用期间的方向输出，不调用串口关闭。
- 应用进入前台或收到小板插入事件时提前准备 USB；先检查系统授权，有授权直接连接，没有则按设备连接会话至多自动请求一次。
- 拒绝后不因恢复界面或反复切开关而无限请求；明确的“重试授权”允许再次请求。拔出设备会清除请求去重标记。
- 只为用户的小板 VID/PID 注册 USB 处理入口，不匹配所有外设。首次授权和系统默认处理选择仍由用户 / 系统决定。
- `UsbPermissionGate` 只记请求尝试，不缓存或伪造系统权限。
