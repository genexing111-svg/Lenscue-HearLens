# v0.13.1：保留字幕与顶部语音胶囊

## 按住肩键后的显示

- 已经显示的常驻字幕继续留在原处，收音和播放期间不再清屏。
- 暂停常驻语音识别的上传 / 请求，避免本轮语音重构重复进入常驻字幕；语音重构本身的识别请求正常运行。
- 环境音名称和方向光晕在本轮期间隐藏，环境音分类暂停。
- 说话胶囊移到每只眼画面的上方居中，距图像上沿约 16 个参考像素；文字变多时向下展开，上沿位置固定。
- 原 SVG、蓝紫渐变响度条、静音圆点、半透明蒙板及长文换行继续保留。普通预览和无线画面同步调整。

## 播放结束之后

恢复原先开启的常驻字幕及环境音功能。已有字幕在恢复连接时继续显示；新结果到达后接续更新，仍按原来的最多四行显示规则滚动。

新识别连接使用独立的句子编号空间，避免新会话的第 0 句覆盖旧字幕；不同会话的相同说话人编号也不直接合并成同一个发言块。

若恢复连接失败，保留已有字幕并在状态中说明错误。手动“清空语音字幕”或明确关闭字幕仍会清除显示；退出应用的原有行为保留。

## 验证与安装

v0.13.1 / versionCode 26 已覆盖安装到红米 K80 Pro。135 项单元测试及手机端受控显示 / 暂停保留检查通过。用户表示稍后回来体验，实际使用中的保留与恢复效果仍待确认。

本次没有修改 PTT 云端协议、Key 或音频播放逻辑，也没有重复调用云端 API。手机测试使用固定文字及隔离设置，不采集现场音频。

## 回滚

修改前 v0.13.0 的 APK、源码和校验值已保存到 `dist/rollback/v0.13.0-before-top-capsule/`，附 `回滚到v0.13.0.ps1`。此前各回滚版本继续保留。

有线连接并授权 USB 调试后，可用脚本执行同签名测试包的 `adb install -r -d`，尝试保留数据回滚。系统拒绝时脚本停止，不自动卸载；本次未执行降级。
