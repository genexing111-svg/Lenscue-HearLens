# v0.10.2 肩键轮盘验证记录

日期：2026-09-27。设备：红米 K80 Pro / Android 16，SC-B03-E01A 遥控器。

## 原因与修复

最初五次同键采样均为 Android `BUTTON_Z（101）`，v0.10.1 补充此映射后，用户确实看到了轮盘。但后续肩键发送了 `BUTTON_A（96）`，被旧的通用手柄规则当成确认，因而打开普通设置。

按“同一肩键三次 → 实体 A 三次 → 同一肩键三次”的受控顺序再次对照，应用记录为 **96×3 → 25×3 → 96×3**。所以这里的 Android 键名 BUTTON_A 不等于实体 A。尚未确定遥控器为什么先后发送 101 / 96，不把它断言为某个固件模式问题。

v0.10.2 对已校准为“实体 A = 25 确认”的 SC-B03，兼容肩键 101 与 96。其他普通手柄、未校准的 BUTTON_A 保留默认行为，显式学习的单键映射优先；X/B/Y 校准不变。

## 轮盘交互

- 单击肩键呼出，再单击关闭；松开和按住重复事件不会额外触发。
- 摇杆离开中心死区并进入镜头区域，立即请求对应镜头，高亮约 500 毫秒后关闭。
- 一次打开只提交一次选择，期间忽略摇杆重复包；镜头不可用则保留轮盘供重新选择。
- 自动关闭后，偏转中的摇杆不会继续操作普通设置，须先回中；打开前已经偏转，也须回中后再选。
- 应用失去焦点、后台或遥控器断开时清理快捷状态与定时器；镜头重启期间保持轮盘布局稳定。
