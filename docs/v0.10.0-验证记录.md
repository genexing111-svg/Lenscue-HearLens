## 已完成真机检查

- 红米 K80 Pro / Android 16，通过 ADB 同签名覆盖安装成功。
- 安装后摄像头采集约 60 fps；原双眼缩放、间距、单眼微调和显示设置仍在。
- 系统开放主摄、物理超广角、物理长焦和前置，轮盘按实际镜头 ID 请求切换。
- 原语音模式迁移为“说话人识别”。本轮安装没有自行开启麦克风或云端计费会话。
- 真机设置页截图已检查：五个常用入口、字幕五档、四镜头滑块、绿色开关、暖灰圆角样式；修复首次启动相机目录晚到时未刷新，以及底层文字透出的问题。
- 已读取无线输出中的双眼设置菜单，使用既有双眼中心、相同面板尺寸与字体。
- 本地 ICU 转换检测通过：`汉语 → 漢語`、`漢語 → 汉语`。这是手机本地字形转换验证，不是云端真实语音五档测试。
- 读取旧遥控配置确认四键映射仍保留。本轮按键采样尚未收到实际输入，不能确认实体肩键或 @ 已适配。
