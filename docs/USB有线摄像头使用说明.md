# 听见视界 v0.2.0 · USB 有线摄像头传输

这一版在原有前后摄像头预览、暂停和继续的基础上，将手机摄像头画面通过 USB 数据线传到电脑浏览器。安装包名和手机应用名均已标注 USB 功能。

## 三步开始观看

1. 安装 `听见视界-v0.2.0-USB有线摄像头传输.apk`。它使用与 v0.1.0 相同的包名和签名，可直接覆盖升级。
2. 用支持数据传输的 USB 线连接红米 K80 Pro 和电脑，保持 USB 调试开启、手机已解锁。若出现调试授权提示，允许这台电脑。打开“听见视界·USB有线版”，允许相机权限，保持 USB 传输开启。
3. 在电脑解压“USB电脑观看工具”压缩包后，双击 `启动USB摄像头.cmd`。浏览器会自动打开观看页面。首次使用也可让启动器安装同目录中的 APK。

电脑不需要安装 Android Studio、Java 或 Node.js。观看工具自带 ADB；必须完整解压后运行，不能只把 `.cmd` 文件单独拿出来。

## 手机和电脑分别怎么操作

- 手机切换前置／后置，电脑画面随之切换；前置画面使用镜像。
- 手机“暂停预览”会暂停相机和视频；点“继续预览”后恢复。
- “关闭 USB 传输”仅停止向电脑发送视频，手机仍可预览；重新开启后电脑自动重连。
- 电脑页面提供全屏和重新连接，保持画面比例。手机取景区可能裁切，电脑观看区显示完整传输画面。
- 手机锁屏、切到其他应用或退出时停止相机和传输。解锁并返回本应用后，电脑页面会尝试重新连接。
- 拔线后页面显示连接中断并遮盖旧画面。重新连接 USB 后，若没有恢复，重新运行启动器。
- 使用 `停止USB连接.cmd` 可移除本工具的 USB 视频通道；手机本地预览不会被卸载或关闭。

## 传输方式与功能边界

实际链路是：**手机摄像头 → JPEG 视频帧 → USB ADB 通道 → 电脑本机浏览器**。默认目标为 1280×720、编码上限 15 帧/秒，实际分辨率和帧率取决于相机协商及设备负载，观看页显示实际尺寸与状态。

本版只传相机画面，不传手机桌面、通知或声音。没有拍照、录像、媒体保存、Wi-Fi 传输或云端服务。页面地址 `127.0.0.1` 指电脑本机；手机服务使用本地 Unix socket，没有监听 Wi-Fi 地址，也不申请联网权限。启动器只选择 USB 设备，不使用无线调试连接。

这是通过 USB 调试观看的原型，暂不将手机注册为 Windows 的系统摄像头，因此不会直接出现在腾讯会议、Zoom 等软件的摄像头下拉列表中。

## 常见情况

| 提示或现象 | 处理 |
| --- | --- |
| 找不到 USB 设备 | 解锁手机，检查数据线和 USB 调试；系统若要求选择 USB 模式，选文件传输；再运行启动器 |
| 设备未授权 | 在手机确认“允许 USB 调试”，然后重试 |
| 多台 USB 设备 | 先只保留要使用的手机，再运行启动器 |
| 手机提示未授权相机 | 给本应用相机权限，并保持应用在前台 |
| 等待手机／电脑端无画面 | 确认手机 USB 传输开关已开启，且没有暂停预览；检查相机是否被其他应用占用 |
| 页面有状态但黑屏 | 检查镜头是否遮挡、系统摄像头访问开关是否开启；在手机切换镜头或重试 |
| 端口被占用 | 先关闭之前的本工具连接；不要删除其他软件的转发规则，按启动器提示处理 |
| 拔线后未自动恢复 | 重新插线、确认授权，再双击启动器 |

电脑端观看不需要“USB 调试（安全设置）”中的模拟点击能力；所有摄像头按钮仍可在手机上操作。
