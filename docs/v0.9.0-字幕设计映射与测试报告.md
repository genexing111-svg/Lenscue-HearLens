# v0.9.0 字幕设计映射与测试报告

日期：2026-09-27。设备：红米 K80 Pro，Android 16 / API 36。版本 0.9.0 / versionCode 12。

## 设计来源与优先级

样式参考用户提供的 `MR-Caption-Design-Handoff-20260927(1).zip`，已读取 `DESIGN_SPEC.md`、`IMPLEMENTATION_CONTRACT.md`、最终参数 JSON 和源码，并查看成品参考图。

采用 B 型随换行扩展的矩形底衬，白字、细彩色说话人杠，透明度 75%、外羽化 12、背景模糊 7。底色 RGB(8,12,11)。模糊使用降采样纹理与三轮可分离滤波近似网页高斯效果；文字和颜色杠在材质合成后独立绘制。

用户本次明确要求优先于 ZIP 的演示布局：横向宽度和位置依据另外附带的游戏字幕截图，映射为最大 52% 画面宽度、下方居中、距底部 8%。四行总上限替代 ZIP 的“最近三段、每段固定三行插槽”。没有复制网页的工具条、背景照片、演示人名或模拟语音到运行界面。

## 流畅度收尾

初版同步模糊在字幕持续更新时使显示自动降至约 24 fps，摄像头仍约 59 fps。最终代码已把背景纹理模糊移到独立线程，每次仅处理最新帧，避免在显示线程上等待滤波。

最终优化版已覆盖安装。实际手机绘制缓冲为 3200×1440（屏幕最高），当时摄像头输入为 1920×1440。连续采样 25.03 秒期间：相机平均 59.93 fps，手机显示 52.26–57.35 fps，均值 54.82 fps；平均单帧绘制耗时 1.98 ms。无线成功接收 363 帧，约 14.50 fps，空响应和网络错误均为 0，字幕最大实际行数为 4。原生手机截图与无线双眼画面已检查，左右眼内容、字号与行宽一致，底衬保持局部羽化和模糊。该数据是短时运行结果，不是长时间恒定帧率承诺。

最终 APK 签名和 16 KB 对齐检查通过。沿用原签名覆盖安装，未清除用户数据；个人 API Key 不进入安装包或源码。
