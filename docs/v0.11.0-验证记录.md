# v0.11.0 USB 声源方向验证记录

日期：2026-10-06。基于工作区实际最新 v0.10.4 修改，版本代码 18，包名 `com.hearlens.app`。

## 真实小板观察

- Windows 识别 `USB-SERIAL CH340 (COM3)`，VID `1A86` / PID `7523`。
- 第一轮 115200 / 8N1 被动读取 7 秒，238 字节，内容为 ESP32-C3 启动日志。没有把其中数字当方向。
- 第二轮同参数读取 15 秒，收到 335 字符、19 条真实 `angle: N.0 deg` 记录，包括 354、355、1、339、343、342、341、31、7、351、353、31、236、58、319、318、309、281、280°。
- 读取过程中未发送串口业务命令，未刷写固件；每次采样完成后关闭串口。打开串口的电气控制可能触发部分开发板重启，应用会忽略启动日志，等候角度行。
- 上述只证明电脑串口链路和文本格式，不证明物理方位精度、多个声源的分离能力或手机 OTG 兼容性。

## 实现检查

- USB 主机能力是可选功能；没有连接小板时，原相机、字幕和无线功能继续可用。
- 手机由系统 USB 设备授权，不使用 USB 调试。不申请额外 Android 通用运行时权限。
- 采用固定版本 `usb-serial-for-android:3.11.0` 的 CH340 驱动，MIT 许可证打入 APK 与源码。
- 输入在独立串口线程读取；文本按行解析，处理任意分包，原始文本 / HEX 有容量限制，仅留内存。
- 自动格式严格要求方向字段标签；不识别启动日志中的散落数字。配置后立即生效，换波特率 / 格式重连。
- 正前方值、顺逆时针、超时和显示开关独立保存；不更改现有相机、双眼布局、语音凭据或遥控映射。
- USB 授权回调核对当前待授权设备并再次调用 `UsbManager.hasPermission`；不相信广播中的授权布尔值。
- 拔线、关闭、后台、失效记录和超时均清除有效方向；过期时状态 API 的当前角度为 null。
- 方向提示在相机旋转 / 镜像后单独绘制，不随画面镜像而左右反转；前后左右含义由小板安装朝向与校准决定。
- Wi-Fi 状态只增加 `stereo.direction`，不输出原始串口日志，不新增模拟角度或串口写命令接口。

## 明确待测

本轮 ADB 未发现手机，**未安装到手机，也未执行手机 USB 直连验收**。以下由用户拿到 APK 后测试：

1. OTG 能否枚举 CH340，首次授权 / 拒绝后重试。
2. 有效角度是否持续变化，启动日志 / 无信号时是否正确提示。
3. 正前方校准、右侧验证顺逆时针、前后左右四方向的物理对应。
4. 两眼与无线画面方向提示是否可见且一致，字幕与遥控是否正常。
5. 拔插、后台返回、锁屏恢复、重启后的配置保存与授权恢复。
6. 持续使用的延迟、稳定性、供电和温升。

本轮不进行真实云端语音会话，不更改小板固件。Android instrumentation 仅编译检查，不能记为已在手机运行。
