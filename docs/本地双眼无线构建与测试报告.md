# 听见视界 v0.5.1：高清本地双眼与无线字幕测试报告

测试日期：2026-09-26。设备：vivo S30 / V2464A，ADB 实际读取 Android 16 / API 36，屏幕 1080×2400。包名 `com.hearlens.app`，versionCode 6，versionName 0.5.1。

## 本次修复

用户反馈 v0.5.0 双眼画面清晰度和帧率低。v0.5.1 将手机观看和无线压缩分开：CameraX 原生 YUV 转 Bitmap 后，由手机硬件画布在原生分辨率绘制左右眼；手机观看不再经过低分辨率 JPEG 编解码。无线使用独立单任务编码线程，只取最新帧，降低无线清晰度不降低手机画布分辨率。

本地实际采集 1920×1440，手机横屏画布 2400×1080，每眼可用区域 1200×1080。每眼完整等比显示同一镜头画面，保留用户缩放和位置，可能留黑边。画布像素数不代表每眼内容铺满全部像素；这也不产生真实双摄立体深度。

手机原生设置、动态镜头选择、颜色与双眼布局、文字样式、电脑无线字幕入口均保留。当前 vivo 系统向本应用开放主摄 ID 0 和前摄 ID 1；不虚构未开放的超广角/长焦。普通 Preview + ImageAnalysis 组合本次最高约 30 fps，不将高速录像标称帧率当作本管线能力。

## 10 分钟固定参数连续测试

结果：通过。北京时间 16:54:53 开始，持续 600.41 秒；596 次状态采样全部保持双眼模式、1920×1440 源图、2400×1080 手机画布、1280×576 无线画面，且硬件画布均为 true。原始记录见 `wifi-soak-600s.json` 和 `wifi-soak-log.txt`。

固定条件：主摄 ID 0、采集尺寸档 1920、自动帧率；实际源图 1920×1440；手机原生 2400×1080；无线总宽 1280（实际 1280×576）、最高 15 fps、JPEG 质量 75。保留用户整体缩放 75、双眼间距 −100。保持双眼模式、应用前台；电脑打开一个观看页，同时运行一个有界诊断接收器。诊断仅记录统计，不保存摄像头画面或字幕。

| 电池温度快照 | 前 44.2°C，后 43.7°C；USB 连接，电量 100% |

帧率是计时窗口估计值，略高于 30 或 15 不表示开启了更高的采集档位。无线诊断统计为接收端到帧速度；浏览器还受绘制和请求节奏影响，现场状态通常约 12–13 fps。220 ms 是相邻到帧的最长间隔，不是摄像头到眼睛的端到端延迟。场景以静止背景为主，本轮平均码流约 1.48 Mbit/s，不代表移动复杂场景所需带宽。

测试后保留上述高清参数和用户双眼布局。手机和电脑已经可继续操作。内存与温度为两个时间点的快照，没有持续上升迹象，但不足以推断更长时间的使用表现。

采集、手机实际显示、无线编码和电脑接收是不同测量点。测试 JSON 每秒记录源图尺寸、手机尺寸、硬件画布、帧龄、双眼状态及帧率；网络接收器记录相邻新帧到达间隔。结果只覆盖本次设备、网络和参数，不能保证所有 Wi-Fi 环境同样流畅。

- 桌面 `听见视界-无线双眼控制台.html` 已生成并复制到桌面；自动浏览器安全策略禁止打开本地文件，未完成双击该 HTML 的界面验证。直接在浏览器打开手机提供的完整无线链接已通过实测，不依赖此辅助入口。
- 手机单次 10 分钟测试不能证明长期温升、耗电或内存长期稳定；未进行佩戴后的光学清晰度、畸变和近视矫正验证。
- 未加入语音识别、人物定位、声音分类/方位识别或视频录制。字幕入口是文字传输接口。
