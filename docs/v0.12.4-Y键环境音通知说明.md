# v0.12.4：Y 键环境音感知与顶部开关通知

## 操作

- 应用里的“声音感知”统一改称 **环境音感知**，浅层蓝色开关和详情入口保留。
- 观看时按一下遥控器 **Y**：开启环境音感知；再次按 Y：关闭。普通相机预览及双眼观看均支持，双眼菜单或字幕语言小窗打开时也可快捷切换。
- 顶部出现“环境音感知”通知卡：沿用设置界面的暖灰底板、圆角细边、白色文字、蓝色滑动开关。约 220 ms 滑入，开关约 320 ms 滑动，整条通知约 2.16 秒后收起。
- 长按 Y 或按键自动连发只切换一次；松开后再按才会切换。快速来回按时，动画从开关当前位置反向过渡，不排队播放旧通知。
- 左右眼显示相同动画；无线画面输出同样的卡片。暂停相机时，本地通知仍可播放。

## 已有遥控器校准

本机 SC-B03 已保存的实体 Y 键码为 108，旧功能名为 `minus`。新版兼容解释为环境音感知开关，不要求重新校准，也不重写原有映射，方便旧版回滚。标准 Android `BUTTON_Y` / 外接键盘 `Y` 也有默认映射。

按键学习中的 Y 已改为环境音感知，原有 A 确认、B 返回、X 字幕语言、肩键镜头轮盘保留。减少设置值使用摇杆左。处于按键学习流程时，Y 只用于学习，不会顺便开启麦克风。

## 授权与失败反馈

开关表示环境音功能的开启请求。首次缺少权限时仍遵循 Android 的麦克风 / USB 确认；卡片可显示“等待授权”。拒绝麦克风或启动失败时，开关回到关闭状态并显示原因，不假装已经识别。已经授权时复用既有授权及前台 USB 连接。

本快捷键只开启本地环境音处理及方向显示，不开启云端字幕会话，不新增权限；已单独开启的字幕仍按原设置运行。
