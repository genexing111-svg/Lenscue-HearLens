# 听见视界 v0.9.0 · 四行实时字幕

手机摄像头、手机直连阿里云语音、字幕绘制与左右眼合成都在红米上完成。电脑可通过现有无线观看入口接收带字幕的双眼画面，无需电脑语音后端。

## 开始观看

1. 打开应用，点“实时语音字幕 / 设置”→“开启语音字幕”。使用上一版已加密保存到本机的阿里云配置。如果尚未配置，先打开原“语音测试”页面填写业务空间与 Key。
2. 首次需要麦克风权限时按提示授权，然后再次手动开启。不会因打开相机或打开应用而自动录音。
3. 点击“进入双眼观看”。麦克风和相机同时工作，真实原文出现在画面下方。
4. 双眼模式下按 SC-B03 的 X 打开菜单，进入“更多设置”，可开关实时字幕、切换原文/译文、清空字幕。常用首页仍为五个常用设置加“更多设置”。
5. 停止时选择“停止语音字幕”，等待尾句。切后台、离开相机页面或锁屏会取消录音与云端连接；返回后手动重开。正常单眼界面旋转导致页面重建时也需要手动重开；双眼模式下旋转沿用既有活动内适配。

## 显示规则

- 采用设计包 B 型底衬：白色中等字重正文、细说话人色杠、近黑半透明底衬、向外羽化、仅背景轻微模糊。不会模糊文字。
- 按用户另外提供的截图调整位置：字幕列位于每眼有效摄像头画面的下方中央，最大宽度默认 52%，底部安全距离默认 8%。这是对参考图片的比例映射，非设备光学标定值。
- 列内文字左对齐，左边缘保持固定；底衬按当前文字扩宽、遇换行扩高。短句不预占整条宽度。
- 总计最多 **四条实际文字行**，不是四段发言。超出时移走最早的一行，保留最新四行；没有人为逐字播放延迟。
- 云端 speakerId 变化时立即另起一行并分段，同一编号使用相同颜色。未返回编号时用中性色，不假造身份。默认显示原文；可切换英文或中文译文，原文与译文不同时占两套行数。
- 云端中间结果回改时替换原句，不重复追加。字幕不根据音量改变字号或颜色。未收到文字时不绘制空底衬。
- 两眼字幕使用相同字号和最大行宽，分别跟随已调节的左右眼画面中心。摄像头左右眼图像尺寸微调不会使字幕出现不同字号。

## 调整

“实时语音字幕 / 设置”→“字幕宽度、位置和材质”，也可从“手机自定义设置”进入。

| 设置 | 默认 | 范围 |
| --- | --- | --- |
| 最大宽度 | 52% | 35–80% |
| 距画面底部 | 8% | 3–30% |
| 字号比例 | 100% | 70–160% |
| 底衬透明度 | 75% | 0–100% |
| 向外羽化 | 12 | 0–24 参考单位 |
| 背景模糊 | 7 | 0–16 参考单位 |

75% 透明度对应 25% 底色不透明度。羽化和模糊按字号映射到手机像素，使用原生材质实现，不直接照搬网页像素。模糊纹理由独立线程更新，显示使用最新可用纹理，不等待或积压视频帧。

原有镜头、相机参数、每眼尺寸/位置、无线画质、手动文字接口和遥控映射保留。手动文字仍使用旧版的独立设置；实时字幕有内容时优先显示实时字幕。清空实时字幕后可显示原有手动文字。

## 当前边界

采用已验收的 LiveTranslate 接口取得原文与说话人字段。能否正确区分某次真实换人取决于云端说话人识别，应用在收到编号变化后立即换行；不承诺云端零延迟或百分之百准确。

本版是随画面显示的底部字幕，没有人物头顶定位、世界空间锚定或真实双目深度。仍不保存录像和录音。语音内容在内存中用于当前字幕，不写入持久字幕历史；授权的无线观看端会收到带字幕的画面。

## 开发与构建

主要文件：`CaptionModel.kt`（语音段与四行排版）、`CaptionPainter.kt`（原生材质与文字）、`LiveCaptionSession.kt`（相机页的语音生命周期）、`LocalStereoEngine.kt`（单眼、双眼及无线合成）。

构建：`scripts/build.ps1 assembleDebug lintDebug testDebugUnitTest`。

打包：`scripts/package-mr-captions.ps1`。

额外真机渲染用例位于 `app/src/androidTest`，其演示文字和设计测试背景只进入测试 APK，不进入用户安装的应用 APK。系统若阻止独立测试组件安装，不能把这些用例当作已通过。
