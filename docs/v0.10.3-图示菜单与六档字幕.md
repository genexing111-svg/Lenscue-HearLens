# v0.10.3 · 图示菜单、A 菜单入口与六档字幕

## 本版操作

| 场景 | 按键 | 功能 |
| --- | --- | --- |
| 普通双眼观看 | A | 打开设置菜单 |
| 普通双眼观看 | B、摇杆、Y | 不打开菜单 |
| 菜单内 | A / B | 确认 / 返回；常用页的 B 关闭菜单 |
| 菜单内 | 摇杆上下 / 左右 | 选择项目 / 调整当前值 |
| 双眼观看 | X 或 @ | 直接打开字幕语言滑块；再次按可关闭 |
| 语言滑块内 | 摇杆左右、A、B | 预览选择、确认应用、取消退出 |
| 双眼观看 | 肩键 | 单击开关镜头轮盘；摇杆选镜头，高亮半秒后收起 |

A 是唯一通过遥控按键打开普通设置菜单的入口。手机触屏仍可打开设置，方便不使用遥控器时操作。已有 SC-B03 肩键 96 / 101 兼容和 A/X/B/Y 校准保留；原先保存为“菜单”的 X 映射自动解释为“字幕语言”，无需重新校准。

## 字幕入口合并

常用页只保留一个“字幕语言”入口，顺序如下：

**关闭字幕 → 快速识别 → 说话人识别 → 转译为简体中文 → 转译为繁体中文 → 转译为英文**

选择识别或翻译档并按 A，开启或切换对应字幕；选择最左端并按 A，停止采集并立即清空画面字幕。服务停止过程中返回的尾句不会重新显示。左右浏览选项后按 B 不会应用；仅仅打开设置、进入双眼或安装应用均不会自动开启麦克风。

若麦克风尚未授权，会提示先授权并重新选择字幕语言。字幕仍由手机直连已配置的阿里云接口，不依赖电脑后端，不把 Key 写入安装包。

## 界面修正

- 删除双眼菜单的“1/5 · 上下查看更多”提示。
- A/B/X/Y 使用用户提供的真实按键外形 SVG，保留镂空字母，不使用系统字体替代。
- 摇杆方向、肩键和 @ 使用补充矢量图示。菜单、语言滑块、镜头轮盘、按键校准 / 学习及帮助中的按键引导统一图示；按钮的中文功能说明保留。
- 滑块标题、当前值和轨道使用独立区域，按实际字体度量放置，不共享基线。双眼菜单、深层设置和语言快捷滑块一起调整。
- 关闭按钮改为以圆心绘制两条交叉线，返回箭头也按几何中心绘制，不再依赖“×”字符的字体基线。
- 两眼仍沿用已有校准中心和相同尺寸，手机与电脑无线回传使用同一套图示。
