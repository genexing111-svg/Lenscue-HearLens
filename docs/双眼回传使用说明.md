# 听见视界 v0.3.0 · USB 全幅摄像头与双眼文字回传

这一版的路径是：**手机摄像头 → USB → 电脑显示完整取景、生成左右眼画面和文字 → USB → 手机横屏显示**。图像合成在电脑浏览器进行，手机接收合成后的画面用于夹持式眼镜观看。没有 Wi-Fi 或云服务，没有自动保存照片、视频或文字。

## 安装与启动

1. 手机安装 `听见视界-v0.3.0-USB全幅摄像头-双眼文字回传.apk`。与旧版签名相同，可直接覆盖安装。应用显示名为“听见视界·USB双眼回传”。
2. 解压同版本电脑工具包，用 USB 数据线连接红米 K80 Pro，解锁手机，保持 USB 调试开启，并允许这台电脑。
3. 电脑双击 `启动USB双眼回传.cmd`。工具会检查手机应用、建立 USB 转发并打开电脑观看页；旧名称 `启动USB摄像头.cmd` 也能使用。普通 APK 安装不需要 USB 调试，本版电脑传输需要。
4. 保持手机应用在前台、允许相机权限、开启 USB 传输。电脑画面就绪后**自动开始双眼回传**，手机自动切换成横屏双眼画面；初始按钮显示“停止双眼回传”，“手机横屏双眼显示”默认勾选。
5. 在电脑右侧“手动文字”框输入内容，文字会随新帧叠加到左右眼画面并传回手机。清空文字框可取消文字；当前最多输入 120 个字符，排版最多显示 4 行，超出部分以省略号表示。没有语音转文字或 AI 识别。
6. 点击“停止双眼回传”会停止回传并退出手机双眼显示，电脑仍保留原图和合成预览；点击“开始双眼回传”可重新启用。单独取消“手机横屏双眼显示”只退出手机的双眼显示，电脑仍继续合成回传。
7. 手机双眼模式中，轻触屏幕显示“退出双眼观看”按钮；也可使用系统返回操作。双眼模式下遇到回传中断或画面过期，会清除旧图并显示等待提示。

电脑工具包名为 `听见视界-v0.3.0-USB双眼回传电脑工具.zip`，自带 ADB，不需要安装 Android Studio、Java 或 Node.js。电脑入口为本机 `http://127.0.0.1:18765/`；应先运行启动器建立有线通道。停止连接时先关闭工作台页面，再运行 `停止USB连接.cmd`，重新使用再运行启动器。

## 戴入 G05 Pro 前调整

用户提供照片中标注 SHINECON / 千幻魔镜 G05 Pro，属于手机夹持式双目观看设备。包装标称瞳距 58.5–70.5 mm；照片没有提供视场角、畸变系数或光学标定文件。软件不会把“45 mm”擅自当作准确焦距。盒身与标签的尺寸、重量不一致，不用于软件标定。

- 先在电脑与手机上确认两个眼区都有完整画面，再将手机横向放入眼镜；保持后置摄像头未被挡住，给 USB 插头和线缆留出位置。
- 两眼显示来自**同一颗摄像头**，没有真实双摄视差，也没有头部追踪或空间定位。软件中的眼间位置调节是屏幕位置校准，不是以毫米精确测量瞳距。
- 用眼镜自身的机械调节配合页面的画面缩放、左右眼位置调节，使两眼容易融合。软件始终保持完整图像的比例，超出区域会限制调整；看到黑边是保留完整画面的结果。
- 当前没有针对这副镜片标定的畸变校正。先坐着调试，出现眩晕或无法融合时取下眼镜并重新调整；不要依赖测试版画面行走或避障。

## 帧率、清晰度与延迟

默认“自动 · 不额外限速”不再施加旧版 15 fps 上限。应用查询当前摄像头和 Preview＋ImageAnalysis 组合支持的普通帧率范围，选择可用最高档；电脑按新帧到达速度合成和回传。拥塞时丢弃旧帧，只保留最新画面，不累积视频队列。

K80 Pro 的普通前后摄像头元数据最高为 60 fps。专用高速录像的 120/240 fps 不等于这条双向实时管线能达到的帧率。请求值、相机帧率、编码上行、回传以及手机绘制帧率是不同指标；以页面与测试报告中的实测结果为准。编码、电脑浏览器、回传解码、光照及温升都会影响最终效果。

页面提供以下调整：

| 页面设置 | 范围与首次默认值 | 作用 |
| --- | --- | --- |
| 请求帧率 | 自动（默认）、15、24、30、60、120 fps | 自动选择可用最高普通档；手动值是请求或限制，不保证达到该数值 |
| 相机图像宽度 | 640、960（默认）、1280、1920 | 调整采集与编码尺寸，4:3 优先，最终尺寸以设备返回为准 |
| JPEG 质量 | 45–95，默认 75 | 较低值减小数据量，较高值保留更多细节；用于相机上行和电脑回传编码 |
| 回传画布宽度 | 960、1280（默认）、1600、1920、2560 | 双眼合计宽度，高度按手机横屏比例自动计算 |
| 图像缩放 | 50%–100%，默认 100% | 在每眼区域内等比放置完整图像，缩小后留出更多空白 |
| 两眼中心间距 | 滑块 −100 到 100，默认 0 | 在留白允许范围内调整两眼中心；结果显示为画布宽度百分比，不是毫米瞳距 |
| 文字字号 | 18–64，默认 32 px | 以宽 1280 的画布为基准，随回传画布宽度同比缩放 |
| 文字高度 | 10%–90%，默认 78% | 调整文字块的纵向位置，接近边缘时自动保持文字在画布内 |

文字与双眼布局随下一帧更新。修改相机请求帧率、图像宽度或上行 JPEG 质量后，点击“应用传输设置”；重新配置相机时短暂清屏属于正常过程。JPEG 质量滑块也会即时作用于电脑回传编码。手机保存已经应用的传输设置，工作台连接后会读取它们，因此不一定每次都显示首次默认值。“重置参数”恢复上述默认值并应用传输设置，不清空手动文字。

“全幅”指保留应用取得的整幅源图，浏览器与左右眼排版不裁去其边缘；不代表读取了传感器全像素原始数据。黑边用于保持比例。

降低分辨率与画质可能提高帧率；提高回传分辨率便于看清文字。测试结果记录的是当时设置下的表现，不代表 USB 接口物理带宽极限。双眼重复同一源帧不增加有效采集帧率。

页面分别显示“相机采集”“USB 上行”“PC 合成”“手机收到回传”“手机实际显示”和“回传帧龄”。其中“手机实际显示”来自应用绘制新帧的回调计数，不是仪器测得的屏幕扫描帧率；“回传帧龄”也不是完整的端到端延迟测试。已完成与待完成的验证以 [双眼回传构建与测试报告](双眼回传构建与测试报告.md) 为准。

## 暂停、断线与问题处理

应用切到后台、锁屏或暂停后停止取景和传输。恢复前台后电脑自动尝试重连。失联或源帧过期时，电脑与手机隐藏旧图；手机全黑底等待提示不是在本地绕过电脑显示。

- 只有电脑原图、没有手机双眼：检查手机应用是否在前台，以及“手机横屏双眼显示”是否已勾选；如果按钮显示“开始双眼回传”，点击恢复，再观察手机显示帧率是否大于零。
- 手机显示等待：检查回传是否开启、电脑页面是否仍打开、USB 连接是否存在。
- 没有取景：检查镜头遮挡、相机权限、系统摄像头访问开关和其他占用相机的应用。
- 授权错误：解锁手机，确认 USB 调试弹窗，然后重新运行启动器。
- 安装被系统拦截：按手机提示确认本次 APK 安装；不要卸载旧版来绕过签名问题。
- 延迟或掉帧：先降低相机/回传分辨率或 JPEG 画质，再看实测帧率；不要只调高目标数字。

## 开发接口与后续接入

浏览器文字输入口已能真正显示文字，后续语音识别模块可替换文字来源。此版本不连接语音服务，也不产生模拟字幕。

USB 服务使用 Android `LocalServerSocket`，由 `adb -d forward tcp:18765 localabstract:hearlens_usb_video` 连接；手机没有 TCP 或 Wi-Fi 监听，也没有 INTERNET 权限。接口仅供这台已授权电脑通过 ADB 使用：

- `GET /status`：相机状态、会话 ID、设置、支持帧率、上行/回传/显示指标和横屏尺寸。
- `GET /stream`：全幅正向 JPEG 多段流；每帧含 `X-Session-Id`、`X-Frame-Id`。
- `POST /settings`：JSON 设置 `fps`（0 为自动）、`quality` 和 `maxWidth`。
- `POST /display`：JSON `{"enabled":true}` / `false`，进入或退出手机双眼显示。
- `POST /return-frame?session=...&source=...`：`image/jpeg`，传入电脑合成帧。必须对应当前会话中的新鲜源帧；过期或乱序请求拒收。返回 204 表示接收成功，不等于已经完成手机屏幕扫描显示。

只有一个编码／提交链工作，异步回调必须保留对应源帧的会话和编号。后续若增加 H.264 或其他硬件编码，可替换传输层而保留文字合成与双眼布局；当前版本使用 JPEG 实时逐帧传输，不宣称已实现压缩视频协议或系统 UVC 摄像头。
