# 听见视界 v0.8.0 · 手机直连阿里云

本版增加原生 Android 云端语音协议。红米联网后自行连接阿里云北京 WebSocket，上传手机麦克风音频并接收文字字段，不依赖电脑后端。电脑不参与音频转发；普通使用不需要 USB。

## 使用

1. 在相机主页打开“语音测试（手机直连阿里云）”。相机与双眼界面会按原有生命周期暂停，返回相机后恢复。
2. 连接方式选择“阿里云直连 · 北京”。填写本人北京业务空间标识 `llm-…` 及 API Key。业务空间留空时使用北京通用入口；不同空间或模型的授权需分别检查。
3. 选择“快速转写 · asr”或“同声传译 · live”。live 可选英语或中文目标。
4. 点击“检查接口（不录音）”。手机会进行真实鉴权、模型初始化与正常结束，不访问麦克风。连接成功并不代表已经完成语音识别测试。
5. 点击“申请麦克风权限”，在 Android 提示中允许使用。授权不会自动开始录音。
6. 准备好后点“开始语音测试”。显示“采集中”后说一句话；页面显示采集电平、上传包数、音频秒数、云端原文/译文、最近识别数据和原始协议消息。
7. 点击“停止采集并等待最终字段”，等待“已完成”。“立即取消”会放弃等待尾句；退出本页、切后台、锁屏也会停止采集和连接。

字段仅用于当前阶段的接口验证，尚未显示双眼实时语音字幕。live 返回 `zh` 时保持云端内容，本版不额外生成 `zh-Hant`。

## 凭据与数据

- API Key 仅通过 TLS 发往阿里云官方北京域名，界面不能把云端凭据发往任意自定义地址。
- Key 在填写后点击检查/开始时通过 Android Keystore AES-GCM 加密保存于应用私有目录，不打包进 APK 或源码，不显示在协议日志。主机调试导入时仅使用一次性私有文件，读取后立即删除。
- “清除本机保存的 Key”删除本机密文和输入框内容。卸载会移除本机应用数据；APK 本身不能恢复个人凭据。应用禁用备份。
- 支持临时 API Key；过期需替换。个人测试版直接持有凭据，不提供多人账号、额度分发或服务端凭据管理。
- 不保存音频或摄像头录像。调试版将当前响应字段与计数暂存于应用私有缓存，便于 USB 验收；退出测试页面即删除。缓存不含 API Key。交付报告只保留必要测试结论。
- 保留原有后端桥接模式；只有主动选择此模式时才使用原来的 `/api/config` 与 `/stream`。

## 协议与开发

ASR：`qwen-audio-3.1-asr-flash-streaming`，`run-task → task-started → 二进制 PCM → result-generated → finish-task → task-finished`。等待 `task-started` 后才打开麦克风。

Live：`qwen3.8-livetranslate-flash-realtime`，`session.update → session.updated → input_audio_buffer.append → session.finish → session.finished`。仅请求文本输出，音频包用 Base64 编码。按明确的 input/output item 关联原文、译文，保留说话人 0 和独立终结标志。

两模式输入均为手机内置麦克风，16 kHz、单声道、PCM16LE，20 ms / 640 字节分包。权限失败、模型错误、断网或超时会停止，不自动重连录音。停止顺序为音频尾包、结束请求、最终字段。

相机、手机本地双眼、无线观看、更多设置及 SC-B03 映射沿用前版。本轮不改镜头、渲染或遥控算法，也未重新进行前版十分钟视频压力测试。

开发入口：`AliyunSpeech.kt`（直连地址/协议/同传字段关联）、`SpeechClient.kt`（会话与采集生命周期）、`PhoneMicrophone.kt`（音频）、`SpeechCredentials.kt`（本机凭据）、`SpeechActivity.kt`（验证页面）。

构建：`scripts/build.ps1 assembleDebug lintDebug testDebugUnitTest`。默认 Android debug 签名供个人覆盖测试。

官方参考：[模型说明](https://help.aliyun.com/zh/model-studio/qwen3-8-livetranslate-flash-realtime)、[Live 客户端事件](https://help.aliyun.com/zh/model-studio/live-translator-client-events)、[Live 服务端事件](https://help.aliyun.com/zh/model-studio/live-translator-server-events)、[ASR 流式转写](https://help.aliyun.com/en/model-studio/real-time-speech-recognition-user-guide)。同时参照用户提供的交接包。
