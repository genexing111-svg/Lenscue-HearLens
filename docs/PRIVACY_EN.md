# Privacy and prototype boundaries

Camera preview is local and the app does not automatically save video or recordings. Enabling the observer sends the composite view across the local network. Enabled cloud speech sends audio to Alibaba Cloud; local environmental classification does not need cloud inference. Explain those routes to participants.

Phone API keys use Android Keystore. Windows DPAPI protects the receiver token. Neither belongs in a public repository or presentation. Cloud provider processing/retention still needs to be understood; no automatic local recording does not mean no external processing.

PTT produces generated restatement. The wearer must retain control over the intended message. Fluent output is not evidence that every meaning was preserved. Voice similarity and performance across speech patterns need evaluation.

External trials require clear consent, stop controls and an accessible phone-screen alternative. Start with short, seated tasks. This camera-mediated viewer is not a validated emergency alert, navigation aid, treatment or optical AR product.

The public package excludes raw personal recordings, live keys, signing keystores, token stores and account exports. Synthetic and public fixtures retain provenance notes.
