# v0.12.0：本地环境音、方位光晕与横屏设置

本版整合用户提供的 `environment-sound-handoff-2026-10-03.zip` 和 `Sound-Direction-Glow-Final-20261003.zip`，同时调整横屏设置的布局和控件比例。

## 开启环境音

进入 **手机自定义设置 → 深层设置 → 本地环境音与方向光晕**，点“开启本地环境音识别”。如系统询问麦克风权限，允许后再点一次开启。初始保持关闭，离开应用后停止，返回需手动重新开启。

模型随 APK 安装，在手机本地 CPU 运行，不需要环境音 API Key、电脑服务器或互联网，不保存音频文件。它与原有语音字幕共享同一个手机内置麦克风；**如果同时主动开启原有云端语音字幕，音频仍会按原设置发送到语音服务**。环境音功能不会主动开启云字幕。

模型使用交接包中的同一份 YAMNet，支持完整 521 类、简体中文 / 繁體中文 / English 名称。分类结果不等同于真实事件百分之百发生；未确认时名称带“可能是”。敲击类显示“敲击声”，不把通用敲击直接断言成敲门。

## 光晕与声音名称

- 声音方向对应的画面边缘出现蓝色光晕，旁边是单行白色名称、灰色磨砂底板。
- 默认光晕亮度 **85%**、向内扩散 **80 参考像素**、方向范围 **60° FWHM**；标签蒙版透明度 **80%**，即灰色染色不透明度 20%。可在手机即时调整并保存。
- “蒙版透明度”只调整灰色染色，不使白字一起变透明。标签下方局部背景模糊，中央画面保持清晰。
- 一次提示 180 ms 亮起、保持到 1200 ms、2800 ms 完全消失；减少动态效果时静态显示 2600 ms。
- 同类、附近方位的重复结果在一次提示生命周期内合并，不无限续亮；不同结果最多同时显示 3 个。连续声音结束一轮后，有新识别结果才重新提示。
- 语音字幕占据下方时，声音名称尽量避让字幕区域；光晕仍保持原来的方位。历史提示是最近的事件，不是多个声源独立跟踪。

## 与 USB 小板关联

先按原有方法连接小板并完成 **正前方 / 左右校准**，再开启环境音。原有校准值继续保留。

分类模型只输出声音类型，小板只输出角度，二者没有共同声源编号。本版从同一约 975 ms 音频窗口内接收到的小板角度计算稳定方向，作为**同期方位估计**。多声源、反射声、手机与小板位置差异都可能导致类型与角度不属于同一来源。

- 无同期角度或角度明显跳动：只在画面中央显示声音名称，不猜测方向。
- 改变前方基准、左右方向或 USB 会话后：旧方向提示清除。
- 可关闭“按同期 USB 信号估计方位”，单独使用声音分类。
- 光晕上沿 = 正前方，下沿 = 正后方，左右对应水平方位；不表示高度。
- 关闭环境音后，原来的 USB 数字方向提示仍可使用。

## 横竖屏设置调整

- 竖屏保留原来的上下排列。
- 横屏模式条的名称和当前值移到左侧、左对齐；模式条在右侧独占足够高度，不再被三层文字挤扁。
- 模式条已选部分与开启的开关统一为蓝色；关闭状态保持灰色。
- 开关使用约 1.75:1 的固定胶囊比例与圆形滑块，避免厂商控件拉伸。
- 同时更新手机原生设置、双眼设置及字幕语言快捷条；触摸计算跟随新的绘制位置。原有遥控按键映射不变。

## 实际速度与使用边界

真机公开样本检查中，模型单次 CPU 推理约 1.6–2 ms；这不是从声音发生到看到提示的总延迟。模型需要约 975 ms 的音频窗口，后续每 480 ms 更新一次，连续确认还可能增加等待。相机、音频采集、绘制与传输的长时间综合表现仍需实景测试。

手机默认请求未处理录音，系统不支持时采用语音识别音源，并尝试关闭可控制的自动增益、降噪和回声处理。硬件内部的处理未必能全部关闭，诊断页显示实际音源及可查询效果器状态。

本版没有重新训练模型，也没有证明每种声音的识别准确率或多人多声源的可靠对应。请按实际场景测试敲击、门铃、倒水、脚步以及说话时的混合声音。
