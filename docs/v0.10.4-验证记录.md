# v0.10.4 字幕蒙板验证记录

日期：2026-09-28。目标手机：红米 K80 Pro / Android 16。

## 实现检查

- 语音字幕直接复用 `SettingsPainter.panel`，蒙板颜色、渐变与边线均来自设置菜单。
- 移除字幕模糊线程、模糊纹理缓存、场景重绘回调和羽化贴图生成；本机预览与双眼 / 无线两条路径都不再调用旧模糊实现。
- 升级迁移保留宽度、位置、字号，并记录新材质版本；旧 blur / feather 值不会重新启用。诊断接口保留这两个字段为 0。
- 两项迁移回归检查覆盖自定义布局保留、透明度保存与旧模糊参数忽略。

## 构建与真机

- `assembleDebug lintDebug testDebugUnitTest compileDebugAndroidTestKotlin` 全部通过。
- JVM 测试 82 项，0 失败 / 0 错误。Android Lint 0 错误、9 条建议性警告。
- APK v2 签名与 16 KB 对齐检查通过；权限保持原有摄像头、麦克风、网络、网络状态及应用内部接收器权限。
- v0.10.4 已覆盖安装到手机。实际诊断材质为 `settings-mask-v1`，blur=0、feather=0；原有字幕宽度 52%、距底部 8%、字号 100 保留。
- 已读取到手机直连语音的真实四行字幕，渲染 / 编码均没有错误；采样时相机约 60 fps，手机显示约 58 fps。该采样不是性能对比或长测。
- 手机深层设置中可见“语音字幕蒙板透明度”，用户实际调整后参数与画面更新。旧模糊 / 羽化设置已移除。
- 菜单收起后，已通过无线取得无遮挡的双眼四行字幕截图并检查：背景采用暖灰蒙板，文字和说话人色杠正常。用户随后将宽度调为 62%、距底部调为 3%、蒙板透明度调为 64，诊断值与画面同步更新，blur / feather 始终为 0。
- 收尾时 USB 已断开，无线字幕输出仍继续；因此最后一张无遮挡图取自无线回传。此前已读取原生手机截图，不将无线图声称为原生屏幕截图。
- 源码归档核对 142 个文件，未包含本机缓存、签名私钥或云端凭据。交付 APK 与安装使用的构建文件一致。

本轮聚焦字幕材质，不重复全部镜头长测和遥控器校准。单独 Android instrumentation 仅作编译检查，不声称在手机执行。诊断画面仅保留在本机 `.tools/`，不放入源码与交付包。
