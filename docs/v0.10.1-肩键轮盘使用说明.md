# v0.10.1 · 肩键映射修复与单击轮盘

本版修复 SC-B03 肩键未触发的问题，并将镜头轮盘改为单击操作。两层设置、五档字幕语言、字幕显示、无线传输和双眼校准继续沿用 v0.10.0。

## 操作方式

1. 进入双眼观看，短按肩键一次，视野中央显示三个镜头的轮盘。
2. 再按肩键一次，关闭轮盘，不改变镜头；B 也可以关闭。
3. 轮盘打开时，将摇杆指向上方主摄、右下长焦或左下超广角，即刻提交镜头切换，无需 A 确认。
4. 选中区域高亮约 0.5 秒，随后轮盘自动关闭。这个反馈期间只接受一次镜头选择，继续拨动不会连续切换。
5. 下一次操作前先让摇杆回中。自动关闭后，仍保持偏转的摇杆不会误打开设置菜单；如果在摇杆已偏转时打开轮盘，会提示先回中再选择。

轮盘颜色和材质沿用暖灰半透明设置面板，左右眼仍使用居中的小面板布局。镜头重启期间轮盘位置保持稳定。相机恢复画面的实际耗时由手机相机驱动决定，可能超过高亮持续的半秒。

## 肩键映射

本机 SC-B03-E01A 连续五次独立采样均发送 Android `BUTTON_Z（101）`。本版将此键绑定为轮盘开关，仅对 SC-B03 生效。`BUTTON_A（96）` 仍是确认键，已有 A/X/B/Y 校准不会重置。

按住产生的重复事件、按键释放事件不会再次开关轮盘。如果切换了遥控器工作模式，导致键值改变，可在深层设置的遥控器设置中使用“学习单个按键映射”→“单击开关镜头轮盘（肩键）”。

## 安装与文件

安装 `听见视界-v0.10.1-肩键映射修复-单击轮盘-半秒高亮.apk`，直接覆盖安装即可，保留当前相机、双眼和遥控设置。无需卸载旧版。

源码归档附在同目录。构建：`scripts/build.ps1 assembleDebug lintDebug testDebugUnitTest`；打包：`scripts/package-shoulder-wheel.ps1`。本版不新增权限，不修改手机保存的云端 API 配置。

v0.10.0 说明中的“按住呼出、松开切换”已由以上单击交互替代。完整检查范围见本版验证记录。
