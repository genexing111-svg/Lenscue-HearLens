# v0.10.4 · 暖灰字幕蒙板

语音字幕背景改用当前设置菜单的同款暖灰渐变、圆角和细边线。字幕背景不再进行高斯模糊，也不再重新复制或采样相机画面；半透明蒙板直接叠在实时画面上。

- 手机普通预览、双眼观看和电脑无线画面使用同一字幕蒙板。
- 保留当前字幕宽度、距底部位置、字号、白色文字、说话人色杠和最多四行的排版规则；说话人变化仍另起新行。
- 升级时将旧模糊材质迁移为设置菜单的默认蒙板。旧版透明度用于模糊底图的着色，含义不同，因此此次材质更新会重设背景透明度；宽度、位置、字号不重置。
- 深层设置中保留“语音字幕蒙板透明度”，移除已经无效的“语音字幕背景模糊”和“语音字幕外缘羽化”。调整过的新蒙板透明度会持续保存。
- 手动文字背景也使用同款暖灰材质，其已有背景强度设置保留。
- A 打开菜单、X / @ 六档字幕入口、最左端关闭字幕和肩键轮盘的操作沿用上一版。

安装 `听见视界-v0.10.4-暖灰字幕蒙板-关闭高斯模糊.apk`，直接覆盖旧版，无需卸载。不会自动开启麦克风。

构建：`scripts/build.ps1 assembleDebug lintDebug testDebugUnitTest compileDebugAndroidTestKotlin`

打包：`scripts/package-caption-mask.ps1`
