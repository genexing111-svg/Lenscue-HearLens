# v0.12.3：后方声音贴边，字幕上移

## 新版表现

- 后方（135°–225°）声音种类标签保留在每眼画面的底边内侧，与其他方向相同的边距、字号及磨砂样式。
- 后方标签出现时，如果与字幕区域接近，实时字幕整体上移，留下间隔；提示淡出消失后，字幕恢复原来设置的位置。
- 不修改你保存的字幕位置、字号或双眼校准值。已设得足够高的字幕无需再移动；左右眼保持相同上移距离。
- 多个后方种类标签沿底边横向排开；名称过长时省略显示，不挤成向画面中央堆叠的多行。
- 本地双眼、普通预览中的实时字幕、电脑无线观看使用相同规则。电脑手动输入的文字在双眼画面中也为后方标签留出空间。
- 无方位的声音种类仍不标为后方；仅有小板方向、没有声音种类标签时，不额外上移字幕。

v0.12.2 的蓝色声音感知开关、USB 提前授权及前台连接复用继续保留。
