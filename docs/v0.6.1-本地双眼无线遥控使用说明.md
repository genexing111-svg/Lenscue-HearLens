# 听见视界 v0.6.1：本地双眼、无线共享、可调分辨率与遥控器

适用本次设备：红米 K80 Pro（24122RKC7C），实机 Android 16 / API 36；G05 Pro 手机式眼镜；已配对的 SC-B03 蓝牙遥控器。

本版只实时取景，不保存录像、不录音、不自动识别语音。通过 Android CameraX 调用手机摄像头，应用内控制系统开放的镜头和采集参数；并非同时启动厂商自带相机应用。

## 安装与开始

1. 安装交付目录中的 `听见视界-v0.6.1-本地双眼-无线传输-居中小菜单-蓝牙遥控.apk`。与旧版使用相同测试签名，可以覆盖安装并保留授权。普通文件安装无需 USB 调试。
2. 打开应用，允许相机，点“进入双眼观看”。摄像头完整画面在手机本地复制到左右眼，等比显示并保留黑边，不裁切源画面；这不是双摄立体深度。
3. 手机装入 G05 Pro 前，确认后置摄像头没有被外壳挡住。手机负责采集、双眼合成与显示，电脑关闭或断网仍可本地观看。
4. 手机和电脑连接可互通的 Wi-Fi，或电脑连接手机热点。在应用打开“无线共享”，点连接状态查看完整地址。电脑用浏览器打开该地址，也可用桌面的“听见视界-无线双眼控制台.html”粘贴地址。
5. 地址包含 `#` 后的访问密钥，仅提供给自己的观看设备。局域网 HTTP 没有加密，应在可信 Wi-Fi / 热点使用。关闭无线共享即可停止电脑访问。

## 手机显示与流畅度

普通界面 → 手机自定义设置 → 手机显示分辨率与帧率。双眼模式也能通过菜单调整。

| 设置 | 含义 |
| --- | --- |
| 手机显示分辨率 | 调整真实 GPU 双眼画布尺寸，并缩放到手机屏幕。红米最高横向 **3200×1440**，每眼可用区 1600×1440；低档 1280×576、1600×720、1920×864、2400×1080、2560×1152。最高档从屏幕模式动态读取。 |
| 相机采集清晰度 | 640 / 960 / 1280 / 1920 尺寸档。控制摄像头源图细节，系统选择支持的实际尺寸；提高显示分辨率不会凭空增加源图细节。 |
| 相机目标帧率 | 0 为自动选择当前镜头与 Preview + Analysis 组合支持的最高普通帧率。具体范围由手机查询；屏幕 120 Hz 不代表该组合有 120 fps。 |
| 手机显示帧率上限 | 自动，或 15 / 24 / 30 / 45 / 60 / 90 / 120 上限。实际不超过相机和屏幕能力；持续超出绘制预算时降档，负载恢复后逐步升档。切换分辨率重新评估。 |
| 无线宽度 / 帧率 / 质量 | 独立于手机显示，默认双眼总宽 960、15 fps、JPEG 质量 60；用户填写的是上限。 |
| 无线自动降负载 | 默认开启。电脑接收或手机无线编码变慢时降低无线宽度、帧率与质量；稳定后逐步恢复，不更改手机显示分辨率。 |

手机显示线程、摄像头转换线程、无线编码线程分别运行。每一步只保留最新帧，不排队积压旧视频。持续卡顿时，可先降低相机采集尺寸或手机分辨率；网络弱时先降低无线档位。实际表现还受场景亮度、手机温度和网络影响，不能保证所有环境绝无卡顿。

电脑状态区分别显示：本地输入、手机绘制新帧、电脑接收帧率，以及真实手机画布尺寸和当前无线档位。“手机显示 fps”测量 GPU 画布提交的新帧，不是镜片处的光学测速，也不是完整的摄像头到眼睛延迟。

## 手机自定义与文字入口

保留系统开放的镜头选择、变焦、曝光、补光、中心对焦；双眼缩放、间距、左右眼单独尺寸和高度；颜色、旋转、镜像、校准图；字幕字号、位置、颜色、对齐、底色与描边。

手机普通界面 → 手机自定义设置 → 文字与字幕，可输入最多 120 字。电脑控制台也可输入字幕，由手机绘制到左右眼，电脑看到相同叠加结果。文字为当前会话内容，不写入历史；需要输入文字时可退出双眼模式使用屏幕键盘。

## SC-B03 遥控器

先在 Android 蓝牙设置完成连接，再收起通知栏，保持听见视界在前台。优先使用遥控器的 Android / 游戏 / 手柄模式；本版不猜测硬件的模式切换组合键。

| 默认输入 | 功能 |
| --- | --- |
| X | 打开 / 关闭双眼设置菜单 |
| 摇杆上、下 | 选择上一项、下一项；保持拨动可连续移动 |
| 摇杆左、右 | 减少 / 增加数值，或选择上一个 / 下一个选项 |
| A | 确认操作；数值项增加一级 |
| B | 关闭菜单；菜单关闭时打开菜单，不直接退出双眼 |
| Y | 减少一级 |

设置菜单在两只眼中各显示一份小面板，中心跟随已设置的双眼画面中心与高度。两眼菜单保持相同大小，标题、选项和数值居中；每次显示 3 项，摇杆上下滚动，其余设置均保留。面板宽度不超过单眼区域的 60%，高度不超过 64%，并进一步限制在相机画面内部。退出双眼需要选中“退出双眼观看”并确认，避免误按返回直接退出。也可轻触双眼画面打开菜单，点击行的左侧减少、右侧增加，点击小面板外关闭。

镜头、相机采集尺寸、相机目标帧率需要先左右选择，再按 A 应用；触屏可点对应行中间应用。长按调整时不会反复重开相机，B 关闭菜单时取消尚未应用的选择。

若实体字母与 Android 键码不同：普通界面 → 手机自定义设置 → 蓝牙遥控器 / 按键学习 → 学习按键映射 → 选择功能 → 按一次实体按键。映射按设备保存，可恢复默认。诊断页显示最近输入，不记录应用以外的按键。鼠标模式能点击屏幕菜单；若遥控器在此模式不发送标准手柄轴，摇杆将移动系统鼠标，需要改为手柄模式才能直接逐项导航。

推荐先使用“一键校准 A / X / B / Y”：手机两眼依次提示要按的实体字母，四步完成才保存整组映射。重复键值会要求重试，取消不会覆盖原映射。电脑控制台也有“校准遥控器四键”入口。SC-B03 发送的音量键和鼠标按钮也可以参与校准；在双眼模式中，它的鼠标按钮按校准结果执行菜单命令。

系统 HOME、电源、系统截获的按键无法由普通应用重新绑定。设备显示“已配对”不代表当前已连接；无响应时先检查遥控器电量、连接状态以及通知栏是否挡在应用前面。

## 恢复与停止

- 锁屏、切到后台会停止相机与无线共享，回到应用恢复。无需外部服务或常驻后台权限。
- 镜头、采集尺寸切换需要短暂重建相机会话；新帧到达后恢复，旧帧过期会清屏。
- 网络断开不影响手机本地显示。电脑页面自动重试；热点地址发生变化时重新打开手机显示的新地址。
- 同一时刻关闭其他占用摄像头的应用。电脑控制台提供手机进入 / 退出双眼按钮，便于装入眼镜后的操作。
