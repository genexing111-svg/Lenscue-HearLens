# 电脑完整控制接口 v1

沿用手机 Wi-Fi / 热点的 `http://IP:18766` 及请求头 `X-HearLens-Key`。原 `/status`、`/frame.jpg`、`/layout`、`/camera`、`/focus`、`/subtitle`、`/view` 接口保持兼容。

## 能力检测

`GET /status` 增加 `appVersion` 与 `controlVersion:1`。电脑必须检查能力，不能对旧版显示“高级设置应用成功”。

`GET /control` 返回当前 `application / captions / environment / direction / speech / ptt / permissions / remote`。`speech` 仅包含工作空间、模型名及 `configured` 布尔值，绝不返回 API Key。

## 修改

`POST /control`，请求体：

```json
{"section":"captions","values":{"widthPercent":52,"bottomPercent":8,"sizePercent":110,"transparency":11}}
```

允许分组：`captions`、`environment`、`direction`、`speech`、`ptt`、`application`、`remote`、`preset`。每个分组严格校验已知字段、类型、范围；`action` 操作与参数编辑分开提交。字幕模式 `choice` 也单独提交。

相机 / 布局数值与原接口一致；其余字段见 `DesktopControlProtocol.kt` 和电脑 `public/catalog.mjs`。操作在手机主线程执行，并要求 App 前台。排队超时的任务取消，避免用户看到超时后又意外修改设置。

方向采样校准为异步 4 秒操作，在 `direction.sideCalibration / calibrating` 查询进度；不改变原有稳定度和过期保护规则。

## 按住说话

```json
{"section":"ptt","values":{"action":"start","lease":"本轮唯一标识至少12字符"}}
```

同一 `lease` 在按住时每约 700 ms 发送 `action:heartbeat`；松手发送 `end`，中断发送 `cancel`。没有新建 lease 的自动重试。手机约 3 秒未收到续期时取消本轮。

浏览器通过本机接收服务代理上述请求；服务端只允许固定手机接口，不提供任意 URL 代理。电脑控制服务采用回环监听、Host / Origin 检查及写请求随机令牌，且不启用跨域访问。
