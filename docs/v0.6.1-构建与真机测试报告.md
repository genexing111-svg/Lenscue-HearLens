# v0.6.1 双眼居中小菜单：构建与真机测试报告

日期：2026-09-27。设备：红米 K80 Pro（24122RKC7C），Android 16 / API 36。包名 `com.hearlens.app`，versionCode 8。

## 修复范围

旧版菜单固定于左右半屏，忽略用户已调整的相机画面间距与高度，文字靠左；每眼面板占半屏宽度 84%、屏幕高度 82%。

新版菜单跟随各眼相机画面中心，使用与画面相同的间距与高度计算。面板宽度上限为单眼区域 60%，高度上限为屏幕 64%，且限制在源画面内（宽度不超过 80%，高度不超过 86%）。两眼面板与字号一致，文字居中，长文字按实际像素宽度适配；每次显示 3 项，通过摇杆滚动全部设置。手机、无线画面与触屏命中位置共用几何计算。四键校准提示也采用该面板。

保留所有镜头、图像、分辨率、无线和遥控设置，未重置用户参数。APK 使用相同测试证书覆盖安装。
