## 实现

新增独立语音联调页，包含后端地址、可选会话令牌、模式 / 目标语选择、配置检查、授权 / 开始 / 停止 / 取消、电平与计数、原文字段、翻译字段、原始 JSON。使用 AudioRecord + OkHttp，按用户交接的自建桥接协议通信；未把云端密钥加入 APK。

新增 `RECORD_AUDIO` 权限。没有新增存储或后台录音权限。网络增加主动 HTTP / WebSocket 请求；为局域网调试允许明文，但语音 URL 校验仅接受私网 / 回环 / `.local` 明文地址，公网需 TLS，不绕过证书校验。配置令牌不保存，录音与识别内容不写文件。
