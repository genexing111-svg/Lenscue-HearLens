# 听见视界 v0.4.0 · 多镜头与 USB 双眼自定义

手机摄像头 → USB → 电脑全幅取景与双眼合成、手动文字 → USB → 手机横屏显示。全幅指保留应用取得的完整源图，不等于读取传感器所有像素。两眼仍来自同一颗摄像头，没有真实立体视差。

## 安装和启动

1. 安装 `听见视界-v0.4.0-多镜头-USB双眼自定义.apk`，可覆盖同签名旧版，保留应用设置。
2. 解压 `听见视界-v0.4.0-多镜头电脑控制台.zip`，用 USB 数据线连接手机，解锁并允许此电脑 USB 调试。
3. 双击解压目录里的 `启动USB双眼回传.cmd`。保持手机应用前台、相机权限和 USB 传输开启。工具自带 ADB，无需安装 Java、Node.js 或 Android Studio。
4. 首次没有其他页面占用时，电脑看到完整原图后自动开始双眼回传。在手动文字框输入内容，左右眼都显示文字。没有自动语音字幕。
5. 多个页面同时打开时，只有一个页面负责回传。需要换到当前页面时，点击“接管双眼回传”；原页面不能继续覆盖新页面的画面。关闭页面后可从另一页接管。

普通 APK 安装不需要 USB 调试；这套有线电脑传输需要。页面入口为 `http://127.0.0.1:18765/`，运行启动器后才有连接。手机没有 Wi-Fi/TCP 监听或 INTERNET 权限。

## 镜头与相机参数

手机普通预览页点击“选择镜头”，或在电脑控制台选择镜头并应用。下拉列表来自手机实际开放的接口，物理镜头初次需要尝试，不能仅凭厂商镜头数量保证可用。系统拒绝或没有产生画面时，应用尝试退回上一个正常镜头，并显示原因。当前选中镜头、活动物理 ID 和实际帧率以状态显示为准。

红米 K80 Pro 的普通接口提供后置逻辑相机和前置相机；后置逻辑相机还公布了主摄、超广角、长焦物理 ID。本版会同时为预览和分析请求同一物理 ID。是否真正可用以本次真机报告为准。逻辑相机可能由系统自动选用镜头；固定物理镜头不提供未经验证的逻辑变焦控制。

- 变焦、曝光补偿、补光灯和中心对焦：仅在当前相机支持时启用。切换镜头会关闭补光灯并重置不适用的相机参数。
- 曝光补偿调节相机采集；电脑“亮度”调节收到后的合成图像，两者作用位置不同。
- 自动帧率不额外限制，选择当前镜头与 Preview＋ImageAnalysis 组合支持的最高普通帧率。手动请求可以降低速度，但不能突破硬件和传输管线限制。
- 相机宽度、JPEG 质量、请求帧率修改后应用传输设置；重新配置期间短暂清屏正常。

## 电脑自定义

控制台按功能分组。画面和文字调整随下一帧生效；原图区用于查看完整相机输入，双眼区用于查看合成效果。

| 类别 | 可调整内容 |
| --- | --- |
| 传输 | 请求帧率、相机宽度、JPEG 质量、回传画布宽度；分别显示采集、上行、合成、回传和手机绘制帧率 |
| 画面 | 亮度、对比度、饱和度、90°倍数旋转、水平镜像；保持比例与完整边缘 |
| 双眼布局 | 共同缩放、两眼中心间距、左右眼分别的垂直偏移与尺寸微调 |
| 检查模式 | 双眼、仅左眼、仅右眼；校准网格与十字，便于对齐，不是视力检查 |
| 文字 | 手动输入、字号、纵向位置、颜色、背景透明度、描边与对齐 |
| 配置 | 预设、本机保存/读取、JSON 导入/导出、恢复默认；配置不保存手动文字或相机硬件设置 |

黑边用于保留整幅图。布局滑块是屏幕相对位置，不是毫米瞳距；画面触及眼区边界后会限制移动或缩小，避免裁切。单眼模式让另一眼区保持黑底，用于分别调整。软件亮度、锐利文字或放大不能矫正近视。

“应用预设”先重置全部显示布局、图像和字体设置，再应用所选预设；保留手动文字、相机硬件参数和采集传输设置。本机配置只保存在当前浏览器的同一页面地址下；刷新或新开页面后需点击“加载本机配置”，不会自动加载。跨浏览器或电脑使用 JSON 导出与导入。

降低源图和回传尺寸、适度降低 JPEG 质量通常可减少编解码工作量。清晰度与流畅度预设便于比较，最终以实测显示帧率为准。120 fps 请求不会自动获得高速录像能力；当前 JPEG 双向管线也不代表 USB 接口物理带宽上限。“手机实际显示”是 View 绘制回调计数，“回传帧龄”不是完整端到端延迟。

## G05 Pro 观看器适配

观看器的瞳距调节用于双眼对齐，软件眼位和布局设置不提供屈光矫正。是否具有独立对焦能力、能否同时佩戴框架眼镜，以及是否支持处方镜片插片，应按实际设备确认。项目目前没有确认兼容的插片方案，保留手机屏幕作为替代观看方式。

先获得清晰单眼图像，再用机械瞳距和软件校准图调整两眼对齐。软件不能根据包装上的“45 mm”推导镜片焦距，也未完成该镜片的畸变校准。详细说明与来源见 [近视与眼镜调节](近视与眼镜调节.md)。

## 停止与恢复

手机轻触双眼画面显示“退出双眼观看”按钮，再点击该按钮退出；系统返回也可退出。电脑可以停止回传；取消“手机横屏双眼显示”也会停止发送并释放回传控制权，此时电脑保留原图和本地合成预览。锁屏、后台会停止相机与 USB 服务；手动暂停停止相机和视频流，USB 状态服务仍保持运行。返回应用后，手机仍在双眼模式且没有其他页面占用时，本页可自动重新取得控制权续传；已在手机退出双眼模式则需要再次开始，不会强行重开；其他页面占用时需要显式接管。过期或断线时清除旧图，不持续显示冻结画面。

没有图像时依次检查：手机解锁、应用前台、相机权限、USB 传输开关、USB 调试授权、数据线与启动器。相机被其他应用占用时关闭占用者后重试。安装遇到签名不符不要卸载绕过，应检查是否使用同签名版本。

同时最多提供两个电脑源图流。反复启动工具可能打开多个浏览器标签页；显式接管的页面会优先获得源图通道，必要时让最旧的观察流断开重试，页面本身不会被关闭。只需要一个画面时，关闭重复观看页可减少额外编码/传输负担。升级 APK 后应刷新旧观看页，使其加载同版本控制台；旧版无页面 ID 的控制请求不能打断已有的新版回传。

## 开发接口

仅供已授权电脑通过 ADB 本地转发使用。手机不保存视频、文字，不录音，无云服务。

- `GET /status`：相机目录、实际选中镜头、硬件控制范围、物理 ID、会话、帧率、回传所有者。
- `GET /stream`：带会话与源帧编号的 JPEG 多段流。
- `POST /settings`：`cameraId`、`zoomRatio`、`exposureIndex`、`torch`，以及 `fps`（0 自动）、`quality`、`maxWidth`。范围由当前相机决定。
- `POST /focus`：`{"action":"center"}`，请求支持的中心 AF/AE。
- `POST /display`：`{"enabled":true,"clientId":"每页面唯一ID","takeover":false}`。另一页面占用时返回 409；显式接管使用 `takeover:true`。
- `POST /return-frame?session=…&source=…&client=…`：当前所有者提交新鲜源帧对应的合成 JPEG。旧会话、重复/过期源帧和非所有者拒收。

页面只保留最新待处理帧，解码、编码与发送各自限制并发，避免长队列延迟。回传所有权用于协调多个本地页面，不是安全认证。后续可在文字输入与合成位置接入真实字幕，当前未加入 AI 识别。
