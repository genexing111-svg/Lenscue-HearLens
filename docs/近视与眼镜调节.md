# 观看器的对焦与眼位调节

本项目的 G05 Pro 是手机夹持式观看器。手机屏幕显示同一摄像头的左右眼画面。软件缩放、字号、眼位偏移和校准网格用于调整显示与对齐，不改变眼睛的屈光度，也不提供视力矫正。

## 适配检查

- 物理瞳距调节用于使镜片中心与双眼位置相匹配。
- 是否具备独立对焦或屈光调节，应以实际设备及其说明书为准。
- 框架眼镜能否同时佩戴、是否支持处方镜片插片，需要对具体观看器进行实物确认。项目尚未确认兼容的插片方案。
- 先确认单眼图像可清楚观看，再调整双眼对齐。当前没有完成镜片畸变校准或佩戴舒适度研究。
- 不能舒适使用观看器的参与者应保留手机屏幕选项。外部测试从短时坐姿场景开始。

此说明仅记录原型的光学与显示边界。个人处方、佩戴史和其他个人健康信息不属于公开项目文档。
